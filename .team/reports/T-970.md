Commands:

- `python3 agent_usage.py sources`

Config is exactly `{version:1,sources:[{provider,kind,...}]}` with one source per provider. Common optional fields are `pool_id` (safe local alias) and `max_age_seconds` (1..604800, default5400). Supported kinds: `codex` (`target_file`, optional `cli`, `codex_home`, `timeout`); `claude-db` and `claude-statusline` (`path`); `opencode-stats` (optional `cli`, `days`1..365, `timeout`); `cursor-admin` (`expected_email`, `token_env`, optional `timeout`); `manual` (`path`) for any of all seven providers. Unknown keys, commands and URLs fail sanitized.

Manual files contain `{observed_at:UTC,windows:[{name:safe_alias,used_percent:number|null,resets_at:UTC|null,window_duration_minutes:int|null}]}`. Output has `schema_version`, `collected_at`, and `providers`, each recording source/scope/identity/time/staleness/status/windows/numeric usage/stable error codes. No cross-provider/pool sums. Historical `observed_*` values remain labeled while stale/reset current percentages become null. Exit0 means all selected sources ok; exit2 means some usable partial/peer data; exit1 means no usable data or config/options error.

Codex reuses `codex_usage.collect`; upstream metadata/IDs/raw errors are excluded, source update time stays unknown, and identity failures empty data. Claude SQLite is bounded regular-file input, mode=ro with query-only and query deadline; its actual `local_output_tokens` column is used, errors are read only by timestamp. Capture whitelists official numeric rate-limit fields, atomically writes0600 and rejects symlink destinations. Cursor uses a fixed endpoint/body, environment-named admin key, Basic auth, no redirects, bounded response/time, exact-email uniqueness and conservative pagination refusal. OpenCode executes only fixed local stats argv, marking rounded figures approximate and scoped to all local providers rather than Go quota.
