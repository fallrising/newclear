The bounded regular-file reader uses SQLite `mode=ro`, `query_only`, a two-second query deadline and a read transaction. Fixed parameterized SQL selects latest limit+1 rows within the now-anchored inclusive range and returns selected rows ascending by timestamp/window. It never selects raw JSON, verdicts or error messages. Unknown/unsupported sources do not invoke another adapter. Missing/malformed DBs fail with sanitized codes. A precision regression ensures equal fractional source timestamps are compared before ISO rendering.

Independent review found that SQLite read-only WAL connections can create missing shared memory and mutate existing shared memory. Rework rejects WAL read/write header modes or existing `-wal`/`-shm` paths before SQLite connects, with `database_wal_unsupported`. Existing `-journal` paths return `database_sidecar_unsupported`. It never removes or changes these sidecars, uses immutable mode, or discards live WAL data. Snapshot behavior is unchanged.
