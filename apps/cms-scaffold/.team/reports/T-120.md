It rechecks complete file/directory state after streaming. Backpressure and stream failures propagate as fixed errors. `PP1CMEDIA1\n` is 11 bytes, followed by an 8-byte unsigned big-endian header length, canonical header, then exact raw file bytes; no padding or trailing payload is emitted.

H03b requires a real empty target, validates header/paths/prefix collisions and available-space reserve before writes, creates only new 0755 parents and O_EXCL/O_NOFOLLOW 0644 files, checks actual UID/GID, hashes and byte counts, verifies exact EOF, and fsyncs files and parent directories.
