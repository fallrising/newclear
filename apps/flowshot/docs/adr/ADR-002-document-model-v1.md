# ADR-002 — Initial document-model v1 freeze

Status: accepted for implementation, 2026-10-23. Authority: SPEC §§5/11 and N03 revision 2. T-007 identified decisions required before the first canonicalizer exists. This freezes initial version 1; it does not migrate existing anchors or alter the promised performance oracle.

- Keep synchronous `buildDocumentModel(source): DocumentModel`. Use local pinned `@noble/hashes` SHA-256; lowercase hex. Source hash covers the original valid Unicode string's UTF-8 bytes, including CRLF and an initial BOM; exclude the initial BOM only from rendering. Reject lone UTF-16 surrogates at the pure function boundary. Canonical hash covers the final canonical UTF-8. No WebCrypto/network or second parser.
- Use unified → remark-parse/GFM/frontmatter → remark-rehype → rehype-raw → sanitize → local explicit-language highlighting → canonical leaf/segment construction → stringify. YAML `---` and TOML `+++` front matter are parser nodes excluded from body/model. No auto-detection for code languages; unknown language safely renders escaped code. Highlighting may only add trusted local spans/classes.
- Use sanitizer defaults narrowed to reader content. Remove executable/embed/form/style/SVG/MathML/template nodes and their contents; retain only inert disabled task checkboxes from GFM. Strip user IDs/names, inline styles, event handlers and user-supplied `data-*` attributes before adding trusted model attributes. Prune `hidden` subtrees before stripping attributes. CSS is not interpreted: inline style is unsupported and removed. Canonical text comes from the final rendered safe content, never unsanitized source.
- Prose uses SPEC NFC/horizontal-space/soft-break rules across adjacent inline leaves, including emphasis/link boundaries. NFC composition across such boundaries must retain correct final DOM text and UTF-8 ranges (test `e` plus combining accent split by emphasis). Hard breaks are newline. Fenced/indented code preserves parser-visible whitespace/indentation and NFC. Inline code follows CommonMark parsing, then NFC. Normalize CRLF without losing original-byte source hints.
- Canonical block boundaries contribute one newline between visible blocks; nested boundaries coalesce, with at most two synthetic consecutive separators. List items/table rows are blocks; table cells contribute one ASCII space between visible cell contents. Trim prose edge whitespace at block boundaries. Do not append a final synthetic separator; preserve a code block's own trailing newline. Empty structural/pretty-print whitespace is not selectable content. These separators may occupy gaps between segment ranges; they are canonical selection content even where CSS supplies the visual boundary.
- Each final nonempty selectable text leaf gets a deterministic AST-path/content-order ID and a trusted wrapper carrying its ID plus canonical UTF-8 start/end. Leaf DOM text equals its canonical slice. Metadata is attached after sanitization/highlighting/normalization. DOM offsets remain UTF-16 and are converted using the actual normalized leaf text, never source hints. Optional original source byte/line hints are conservative; omit when an honest mapping is unavailable. The full model must be byte-identical on repeated builds; duration diagnostics stay outside it.
- Freeze `TocItem` as `{id: string, depth: number, text: string}` in document order. Heading IDs use `flowshot-heading-` plus NFC/lowercase Unicode letters/numbers/marks separated by collapsed hyphens, trim edge hyphens; empty slug is `section`. Duplicate base slugs receive `-2`, `-3`, etc., checking global collisions. Raw HTML IDs cannot override generated IDs. Heading text comes from the same final visible-text traversal.
- Replace all links/images, including raw HTML ones, with trusted controlled metadata. No navigable raw href/src/srcset or arbitrary style URL survives. Classify heading, exact local Markdown and safe external http/https/mailto links; reject file/javascript/data/protocol-relative/unknown schemes, including controls and encoded scheme tricks. Reader callbacks handle action; no OS or filesystem access occurs in the pure model.
- Every image becomes an inert placeholder with visible alt text as the stable canonical caption. Allowed local candidates carry metadata for the later PathGuard-backed loader; remote/data/SVG candidates stay blocked placeholders. Loading an image may add a nonselectable image while preserving caption/segment text, so assets never change hashes/ranges. Reader owns and revokes Blob URLs on replacement/unmount. N02/root own actual binary transport and CSP `img-src 'self' blob:` integration.
- Freeze the TS model/types and pure model public surface in N03's lock with a real source/metadata drift checker and tamper fixture. N03 adds no Rust DTO or Tauri command. Runtime dependencies are exactly pinned below; npm alone generates the lockfile. Root owns App/native/generator composition and keeps N00 contract unchanged.

Official package metadata inspected 2026-10-23: unified 11.0.5; remark-parse 11.0.0; remark-gfm 4.0.1; remark-frontmatter 5.0.0; remark-rehype 11.1.2; rehype-raw 7.0.0; rehype-sanitize 6.0.0; rehype-highlight 7.0.2; rehype-stringify 10.0.1; @noble/hashes 2.4.0. Sources: [remark-rehype](https://github.com/remarkjs/remark-rehype), [rehype-sanitize](https://github.com/rehypejs/rehype-sanitize), [rehype-highlight](https://github.com/rehypejs/rehype-highlight), their official npm registry records. Optional type-only packages must be recorded before use; avoid unnecessary runtime dependencies.

Verification remains four N03 BDD scenarios, 3–5 representative synthetic fixtures, 100-repeat determinism, real DOM leaf mapping/security tests and 1 MiB mixed GFM/CJK/code model below 300 ms with source-map cost no more than twice the no-map baseline. Record hardware and measured output sizes. If this oracle fails, report the failure and optimize or request a documented design decision; never shrink the fixture or relax the threshold to claim completion.

## Initial v1 table validity correction

Independent DOM review found that sanitizing an unsupported caption can unwrap its text directly under a table; later segment spans then trigger browser foster parenting and reverse canonical/DOM order. Before canonicalization, preserve caption content through narrow sanitation and move each caption to an ordinary visible block immediately before its table. Normalize table/section/row children to valid structural children; lift other non-whitespace content into ordinary blocks before the owning table in deterministic encounter order. Preserve valid GFM cells and table structure. Discard structural whitespace only under the existing whitespace rule. No selectable segment wrapper may be emitted into an invalid table context. Tests must parse the final HTML and assert DOM-order segment monotonicity plus canonical-slice equality, including caption and stripped-wrapper cases. This is a correction before initial v1 delivery, not a change to a shipped model schema.
