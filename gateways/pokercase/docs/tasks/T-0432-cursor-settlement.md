## Design and boundaries

Cursor has one process/channel per dispatch and returns ClaudeRun records, unlike Claude reusable replies. A Cursor-specific observation retains raw numeric result fields before translation; a consumer lease integrates with existing BodyAccounting to settle conversion/passthrough/Drop. Never observe synthetic wire usage as raw provider evidence. Startup guard covers reserve→spawn→first_record and is handed to response body; producer observation never binds a new request. Existing protocol text/terminal conversions, error classes, isolation and bounded line/channel limits remain.
