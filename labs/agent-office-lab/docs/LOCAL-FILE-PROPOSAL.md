# 本地單檔修改提案

從已登記專案選擇一個文字或程式檔，輸入修改需求，由本地 OpenCode／Strata 產生完整替代內容。頁面會顯示修改差異、原始內容及提案，並可用原檔名下載。原始專案不會被覆寫，生成程式不會被自動執行或測試。

啟動方式沿用[本地文字任務](LOCAL-TEXT-TASK.md)：

```sh
python3 scripts/office_console.py --project /absolute/path/to/small-project
```

在頁面選 **OpenCode → 單檔修改提案 → 來源工作目錄 → 要修改的檔案**，填寫需求後查看計畫，再確認啟動。例如：「修正 calc.py 的 add(a, b)，讓它回傳兩數之和，保留函式名稱與參數」。來源檔案清單只從已登記目錄取得，HTTP 請求不能任意指定主機路徑。

計畫包含目標檔案、需求及會讀取的來源檔案。任何來源內容在計畫後、執行前改變，都會拒絕舊計畫。執行使用確認時的快照；結果中的原始內容及差異以該快照為準，不代表執行後原目錄的最新內容。下載後要自行套用時，請先確認原檔是否又有新修改。

模型須先讀取選定目標，才能寫出提案。工具只接受原有快照讀取與固定 output.md 寫入；output.md 是私有工作區內的容器，內容是完整替代檔案。原始副本另受 OS sandbox 寫入拒絕保護，不增加 shell、網路、遠端模型或額外寫入權限。

結果入口會重新核對保存的 request、來源快照 hash、目標原文、產物 hash 與 runner 紀錄，再從原文和替代內容計算差異；不採信模型自行描述的修改清單。來源或產物遭改動、連結／格式無效、缺少原生完成或清理證據時，不標示提案完成。相同內容顯示「提案無內容變更」，只有換行格式變更也會明示。

完成只代表取得可審閱的提案，並未驗證任意程式的語法、測試或功能。預覽使用純文字，不執行 HTML／Markdown；下載的是與已核對 hash 相同的完整替代內容，以目標的檔名保存。頁面沒有自動套用、覆寫、執行或重試按鈕。

沿用文字來源限制：最多 16 個檔案、每檔 16 KiB、合計 64 KiB；提案最多 64 KiB，原文與提案各最多 4096 行，差異最多 256 KiB。隱藏項目／不支援副檔名排除，符號連結及特殊檔案拒絕。這一版不支援多檔提案、新增／刪除檔案或空白替代內容，也沒有可直接套用的 patch 下載。

模型推論期間可關閉瀏覽器，之後使用原登入網址重開；不會重送任務。停止仍由操作台既有按鈕處理。資源 guard、Q2_0／32K、單任務鎖與完整清理要求不變；高記憶體壓力下可能停止任務，不自動調高限制。
