# 本地文字任務

用 OpenCode／Strata 閱讀你選擇的文字目錄，依輸入要求產生 `output.md`。適合摘要、檢查清單、說明草稿等文字工作。原目錄保留不動，產物可在頁面查看與下載；不執行 shell、安裝套件、搜尋網路或套用程式修改。

從 lab 目錄啟動，將參數換成一個小型文字目錄的實體路徑：

```sh
python3 scripts/office_console.py --project /absolute/path/to/notes
```

可重複 `--project` 登記多個目錄。頁面選 **OpenCode → 本地文字任務 → 來源工作目錄**，輸入最多 500 字，再查看計畫並確認啟動。例如：「閱讀專案說明，整理安裝步驟與待確認事項」。沒有登記目錄時，其他合成驗收仍可使用。模型環境沿用 [SETUP](SETUP.md) 的 `STRATA_HOME`；只使用現有 Q2_0／32K Strata，不需要 Claude 或遠端登入。

計畫列出來源檔案、任務與輸出檔名。執行前重新讀取來源並核對摘要；檔案新增、刪除或內容改變時，拒絕舊計畫，請重新查看。確認後使用當時的快照，不追蹤原目錄後續編輯。每份計畫只能執行一次，使用既有共用執行鎖；重新整理不重送任務。

## 來源及工具範圍

- 支援 UTF-8 的 `.md`、`.txt`、`.rst`、`.json`、`.csv`、`.py`、`.js`、`.ts`、`.css`、`.html`、`.yaml`、`.yml`、`.toml`。
- 最多 16 個檔案，每檔 16 KiB，合計 64 KiB；最多四層子目錄與 512 個走訪項目。超限會拒絕，請另準備較小的資料夾。
- 忽略隱藏項目及 node_modules、vendor、runs、state、tools、__pycache__、dist、build。符號連結、特殊檔案、非 UTF-8 或含 NUL 的支援檔案會拒絕；目錄路徑本身也不能經過符號連結。macOS `/tmp` 是連結，應使用其實體路徑 `/private/tmp`。
- 模型工具只可讀取快照內列出的 `source/` 檔案與既有 output.md，只可寫入 output.md；最多 24 次工具嘗試，產物最多 64 KiB。OS sandbox 另外拒絕寫入來源副本。
- 每次執行使用獨立 HOME／設定與工作副本，禁用自動壓縮與外部工具；不回退遠端模型。完整 host／Strata 網路及檔案隔離仍未驗收，尚不宣稱可安全處理任意秘密資料。

## 結果與停止

完成後頁面顯示「已產生文件，待確認」。成功條件包括原生完成／模型用量、read／write 工具事件、來源副本不變、產物摘要及清理；這只能核對執行與檔案完整性，內容正確性仍需你確認。文字以純文字顯示，不執行 HTML 或 Markdown 內的程式碼；「下載 output.md」會保存同一份已核對內容。

關閉分頁不會停止模型。需要取消時使用「停止執行」，等待 runner 清理後再派工。此模式完成後會關閉 Office 與本地模型，不保留互動終端，不提供自動重試或繼續編輯；失敗紀錄留在私人 runs／state。模型未依指示產生檔案、來源被修改、hash 不符或清理未確認都不能顯示成功。

工作副本、任務內容及結果包含你選擇的資料，留在本機私人 runs／state；不要將這些目錄或離線結果快照提交、分享。登記目錄只在本次操作台程序有效，重啟時需再次指定。
