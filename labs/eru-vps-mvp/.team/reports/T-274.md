### CLI JSON 是 protobuf projection，不是 stored record

CLI describe/utils.go:146–177 用 encoding/json.MarshalIndent，未用 protojson，也沒有在JSON分支把 resource strings decode為objects。describe/node.go:17–24、describe/workload.go:25–27 直接傳 protobuf objects。Core pinned rpc/gen/core.pb.go 的來源 SHA及相關struct原文保存在manifest與core-proto-excerpts.txt。

| Projection | 允許的來源欄位 | 特殊型別 |
| --- | --- | --- |
| Node | name,endpoint,podname,available,bypass,labels,info,resource_capacity,resource_usage,test | capacity/usage是內含JSON的string；available/bypass/test為bool |
| Workload | id,podname,nodename,name,privileged,labels,publish,image,status,create_time,env,resources | resources是JSONstring；create_time為JSON number(int64)；沒有stored engine_params/hook/user |
| Pod | name,desc | strings |
| WorkloadStatus | id,running,healthy,networks,extension,ttl,appname,nodename,entrypoint | extension為[]byte→base64 string；ttl為int64 JSONnumber |

以上 generated Go JSON tags 均 omitempty，所以 false 的 bypass/test/privileged/running/healthy、空labels/env、null status等會省略；不可要求每列固定具有全部keys，也不可將省略false誤判為不合法。仍需拒絕未列extra keys並對本案必需nonempty identity作嚴格要求；比較raw metadata時不自動normalize原始bytes。

Pod nodes走 describeChOr.collect() 初始化[]，workload list初始化[]，兩者空list輸出[]。Pod list和workload get直接spread RPC slice；nil時可能輸出null，不可籠統宣稱所有command永遠array。非空資料為arrays。Workload get同樣回array而非單object。Dynamic resource projection解析一次JSONstring後應驗 exactplugin/resource schemas；不接受原本已是object的synthetic形狀當真實CLI wireformat。
