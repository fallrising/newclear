- 投入／文檔檔位：未分級。

## 1. MVP 要回答的問題

一頁本機網頁，讓懂 JavaScript、沒學過 autodiff 的開發者看懂兩件事：

1. 「寫出運算」：`y = a × x + b` 用普通 JS 與 Handwired 圖算出幾乎相同的結果。
2. 「調整參數」：用梯度一步一步把 a、b 從錯的值拉回正確值。

完成定義是使用者能解釋結果與限制，不是跑通一段看不懂的範例。

## 2. Handwired 在這裡是什麼

JavaScript builder 用一般 JS 組裝固定形狀的 FP32 數值圖（上游 `Circuit` 類別）；建圖與執行是兩個階段。
它不是把任意 JavaScript 編譯成可微模型。上游有 CPU 執行路徑；WebGPU 只用於特定 demo，MVP 不碰 GPU。
FP32 與 JS Number 精度不同，結果比較要有容許值。

## 3. 第一步：API 核對（HW-0，阻塞後續）

上游文件確認有 `Circuit` builder 與 CPU evaluator（`src/runtime/numeric-ui-core.ts`），
初始設計尚未核對可供外部呼叫的梯度／backward API。HW-0 已確認 `Circuit.backpropagateReference` 可用，入口、限制與最小範例見 [API 支援表](upstream-api.md)。原核對問題如下：

- 如何建一個只有輸入、參數、乘法、加法的圖並在 CPU 執行？
- 能否取得對參數的梯度？
- 授權與載入方式（直接 import 原始碼、或需要上游建置）。

結果寫成一張支援表。**若沒有可用的梯度 API**：MVP 仍做第 4 節的前向對照，第 5 節的梯度改用解析公式並在畫面標明「梯度不是 Handwired 算的」，不捏造 API。

## 4. 前向對照

- 公式 `y = a × x + b`，預設 `a = 1.25`、`b = -2`。
- 合法輸入 `-20 ≤ x ≤ 60`；係數 `0.5 ≤ a ≤ 2`、`-10 ≤ b ≤ 10`。超界、NaN、Infinity、空值在執行圖前拒絕並顯示原因。
- 參考值用普通 JS Number；比較規則 `abs(graph - reference) ≤ 1e-5 + 1e-5 × abs(reference)`，事先固定，不事後放寬。
- 畫面：左邊滑桿（x、a、b），中間公式與節點，右邊兩條路徑結果、差值與通過／超差。改輸入後舊結果立即更新，不殘留舊的通過標記。

## 5. 係數學習（同一頁的第二區）

- 目標 `target(x) = 1.25 × x - 2`，無噪聲；初始 `a = 1`、`b = 0`。
- 訓練資料：`x = -20, -10, 0, …, 60` 共 9 個固定點，不用亂數。
- 內部用 `z = x / 40` 學 `alpha × z + b`（`alpha = 40 × a`），避免 x² 尺度讓學習率 0.05 發散；畫面仍顯示 a、b。
- 損失為平均平方誤差；固定學習率 0.05，「單步」與「跑到 500 步」兩個按鈕。
- 顯示每步的損失、兩個梯度、a、b。損失出現 NaN／Infinity 或係數越界時停止並顯示原因，不截斷、不替換成 0。
- 「重設」回到初始值。另提供一個「學習率 2.0」示範按鈕，讓使用者看見發散失敗。
- 學習只改係數；輸入檢查與比較規則不受影響。降低 loss 不等於所有輸入都正確。
- 互動約定：學習區初始 a=1、b=0，前向區第一次開啟仍保留 a=1.25、b=-2。學習／重設操作將合法學習係數套用到上方並保留 x；手動前向輸入不改變獨立的學習狀態。越界候選顯示在停止原因，不偽裝成已接受的係數。
- 「跑到 500 步」是累計上限，不是每次再加 500；學習率 2.0 示範由固定初始狀態開始，重設清除停止狀態。介面明確標記梯度與 loss 對應的係數狀態。

## 6. 實作形式

- 單一靜態 HTML＋JS，瀏覽器本機開啟；無後端、登入或上傳。依上游載入方式決定是否需要最小建置步驟，若需要新增依賴先問 owner。
- 規則（輸入檢查、參考公式、梯度步進）寫成可在 Node 測試的純函式；不從使用者字串執行任何程式。

## 8. 驗收案例

- HW-A01：x = -20、0、60 及 9 個訓練點，圖結果在容許值內。
- HW-A02：超界、NaN、Infinity、字串與空值在圖執行前被拒絕。
- HW-A03：梯度（Handwired 或解析）在幾個測點與解析式 `dL/dalpha`、`dL/db` 相差 ≤ `1e-4 + 1e-4 × abs(解析值)`。
- HW-A04：學習率 0.05 下 500 步內，9 個點最大絕對誤差 ≤ 0.05 °C；未達標則照實顯示，不調參數讓它過。
- HW-A05：學習率 2.0 時顯示停止原因，而非假裝收斂。
- HW-A06：初學者能說出 builder 與 runtime 的差別，以及「loss 下降不等於一般智能」。

## 10. 何時不適合

不適合取代字串處理、資料庫交易、存取控制或任意 JS；遊戲貨幣、庫存守恆與權限應使用明確離散規則。
此例只用合成教學資料，不處理醫療、工業或安全控制。
