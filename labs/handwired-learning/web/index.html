02 / 用梯度調整係數

為什麼可能有一點差距？

JavaScript Number 使用雙精度；這裡的圖使用 FP32，輸入與運算可能有捨入誤差。差值不必是零，仍可以符合事先設定的容許值。

loss 下降不等於一般智能

上方前向區只比較；下方學習區只調整這條固定直線的兩個係數。九點誤差變小不代表所有輸入都正確，也不表示理解世界或具備一般智能。資料是合成教學示例，不用於醫療、工業或安全控制。
