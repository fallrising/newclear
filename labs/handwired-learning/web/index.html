2固定的運算圖

Builder · 建圖一次
JavaScript 組裝輸入、乘法與加法節點。這是固定形狀的數值圖，不會把任意 JS 自動編譯成模型。

Runtime · 每次執行
把新的 x、a、b 填入 source cells，由 Handwired 的 CPU evaluator 計算輸出。

為什麼可能有一點差距？

JavaScript Number 使用雙精度；這裡的圖使用 FP32，輸入與運算可能有捨入誤差。差值不必是零，仍可以符合事先設定的容許值。
