# Retro Economy

> 狀態：**Proposed／僅設計，尚未實作或試玩**。投入與文檔檔位未分級；本文件不變更作品集決策。

以原創邊境小鎮為起點，探索採集、職業製作、冒險需求與玩家交易能否形成值得再次上線的復古 RPG。長期方向是持久多人世界；第一片只驗證少數真人的短程冒險與互相依賴，不承諾 MMO 容量。

[SDD](docs/SDD.md) 定義 MVP：小鎮、兩種職業、固定價格掛單、物品消耗與一次短場試玩。先證明角色有事可做、交易有理由，再增加地圖及畫面細節。

[OpenMMO Lab](../openmmo-lab/README.md) 與 [Zircon-Godot](../zircon-godot/README.md) 是上游試跑／研究；本 lab 負責原創玩法假設，不複製其啟動工具，也不匯入遊戲素材。此處尚無程式、安裝步驟、遊戲服務或測試結果。
