# RE-0：霧岸鎮規則表

對應 [SDD §§2、4、6–8](SDD.md)。以下名稱、配方、地圖與數值為本 lab 原創的**未試玩設計起點**；RE-1 單人規則的自動執行證據見[報告](../tasks/454-re1-solo/report.md)，RE-2 交易自動驗證見[報告](../tasks/475-re2-trading/report.md)，沒有真人試玩或平衡證據。

| 項目 | 精確規則 |
| --- | --- |
| 開局 | 在霧岸鎮 `(0,0)` 選定鐵匠或藥師，不可轉職；生命 `3/3`、貨幣 `12`、原料 `0`、`tower_stage=0`、`tower_reward_claimed=false`。鐵匠另得行路藥 `1`，藥師另得修補組 `1`；自己的成品為 `0`。補助與補給只在建立角色時給一次，重連／重啟不再給。 |
| 採集 | 任何職業在礫坡終點每動作得礦石 `1`，在潮林終點得藥草 `1`；不扣生命或貨幣。資源點不限次、不枯竭、沒有隨機掉落或等待計時；其他格採集拒絕。 |
| 鐵匠配方 | 只在鎮上，礦石 `2 → 修補組 1`；一次動作做一份，只有鐵匠可做。 |
| 藥師配方 | 只在鎮上，藥草 `3 → 行路藥 1`；一次動作做一份，只有藥師可做。 |
| 移動成本 | 每動作走一條相鄰正交邊，成本為一步；無體力、貨幣或即時等待成本。格子與邊只限下圖，不能斜走、跳格或穿越空白。往返礫坡 `6` 步、潮林 `8` 步、成功塔路 `8` 步；採集／製作各另算一動作。 |
| 路障 | 向前從 `(1,0)` 到 `(2,0)`：若本輪尚未修補，消耗修補組 `1` 並記 `tower_stage=1`；缺少則留在 `(1,0)`，不扣任何資源。已修補可往返，不重複扣；不可繞過。 |
| 遭遇 | 向前從 `(2,0)` 到 `(3,0)`：本輪未勝時，有行路藥便消耗 `1`、生命不變、勝利並記 `tower_stage=2`；沒有則敗退，生命降為 `0` 後立即送回鎮回滿 `3`。先前消耗的修補組不退；沒有其他掉落或損失。勝後本輪往返不再觸發。 |
| 終點／重走 | `tower_stage=2` 才能到塔頂 `(4,0)`。首次到達獎勵貨幣 `8`，永久設 `tower_reward_claimed=true`，同一角色再到不給獎勵、物品或其他進度。回程仍走原路；任何方式回鎮都回滿生命並將 `tower_stage` 歸 `0`。下一輪重新消耗兩成品；沿途後退不退還已消耗品。 |
| 交易（RE-2） | 四種物品都能掛單；每單數量 `1–99`，`price=1–99` 為整筆固定總價，由賣家選定。成功購買只轉移指定物品與貨幣，無手續費、NPC 收購或系統銷毀貨幣。掛單／取消本身不增減物品與貨幣；沒有 escrow，購買時須再次檢查賣家持有足量物品，否則拒絕且掛單仍 open。不可買自己的單。 |

地圖（所有連線雙向；塔路向前依上表檢查，回程不觸發）：

```text
礫坡(-3,0)—(-2,0)—(-1,0)—鎮(0,0)—(1,0)—路障(2,0)—遭遇(3,0)—塔頂(4,0)
                           |
                         (0,1)
                           |
                         (0,2)
                           |
                         (0,3)
                           |
                        潮林(0,4)
```

| 資源／狀態 | 唯一新增來源 | 消耗／去向 |
| --- | --- | --- |
| 礦石 | 礫坡每採集 `+1` | 鐵匠每份配方 `−2`；交易轉移 |
| 藥草 | 潮林每採集 `+1` | 藥師每份配方 `−3`；交易轉移 |
| 修補組 | 鐵匠製作 `+1`；藥師建角補給 `+1` | 每輪首次通過路障 `−1`；交易轉移 |
| 行路藥 | 藥師製作 `+1`；鐵匠建角補給 `+1` | 每輪首次贏得遭遇 `−1`；交易轉移 |
| 貨幣 | 每角色建角 `+12`；首次塔頂 `+8` | 交易轉移，沒有銷毀口；總量應等於 `12 × 已建立角色數 + 8 × 已領塔頂獎勵角色數` |
| 生命 | 建角與回鎮回滿 `3` | 無藥遭遇降為 `0`，立即回鎮恢復；不死亡、不掉背包 |

**首輪與重玩：**鐵匠走礫坡採 `2` 次再回鎮製作；藥師走潮林採 `3` 次再回鎮製作，搭配一次性異職補給即可各自完成 RE-1 首輪。既有角色的補給耗盡後，持續重走需要異職製作供應；自己的配方不能補足缺品。RE-2／RE-3 也可在首輪自發交易，但規則不保證玩家會這樣做，仍須觀察。新建角色仍會得到補助；MVP 沒有防分身套利或長期經濟平衡承諾。

**保存與拒絕：**建角補給與角色建立一起保存；`tower_stage`（`0/1/2`）、`tower_reward_claimed`、背包、生命及貨幣均須與動作原子保存。重啟不重置塔路階段／已領標記。除上表明定的無藥敗退外，資源不足、職業不符、地點不符或非法數量拒絕且不改狀態；重送動作不得重複採集、消耗或領獎。RE-1 已以規則、SQLite、HTTP 與實際瀏覽器測試驗證單人保存／拒絕行為；交易由 RE-2 另以重送、競爭、守恆、rollback 與重啟驗證。
