# Zircon-Godot 學習實驗

> 文檔檔位 **A**，限本次研究與設計投入；遵循[文檔政策](../../docs/portfolio-doc-tiers.md)。
> 狀態：**研究與 SDD，尚未建置或啟動遊戲**。本目錄沒有匯入上游原始碼、遊戲素材或帳號資料。

以 [iamcheyan/Zircon-Godot](https://github.com/iamcheyan/Zircon-Godot) 為參考，學習一條完整但有界的遊戲工程路徑：取得可重現環境 → 登入與選角 → 走一步並收到伺服器校正 → 戰鬥／掉落／拾取 → 修改一個既有規則並回歸。

這是保留 Zircon C# 伺服器與共用協定、以 Godot/C# 重建客戶端的社群專案。原版遊戲的歷史、Zircon 的累積與 Godot fork 的成熟度要分開看；目前證據不足以稱此 fork 已經過商業營運驗證。

## 邊界

- 本輪完成文件與設計；後續執行階段需另行安排。
- 第一個可玩目標是一台本機伺服器、一個客戶端、一張地圖、一個角色。先建立觀察與還原能力，再增加第二個角色。
- 不重寫引擎、不先上微服務／分片、不做完整 MMORPG、不部署公開伺服器，也不把 Web 原型當成交付目標。
- 原始 `.Zl`、`.map`、資料庫與聲音等執行資源保持外置；來源取得與使用條件須逐項確認。此 repo 的 MIT 不會替外部原始碼或素材重新授權。
