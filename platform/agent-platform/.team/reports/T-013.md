Canonical UTF-8 JSON uses server run identity, a deterministic artifact UUID, an allowlist of result/verification fields, exact validated diff bytes, SHA-256 and base commit. Recovery prioritizes the existing result across expired execution deadlines and budget cutoffs, without allocation, prompt or tool rebind. Resultless recovery from finalizing also protects the workspace when a database outage prevented recording the archive-failure reason. Explicit cancellation retains precedence. Missing cleanup proof retains capacity.

Authenticated list/download endpoints return fixed metadata and a safe JSON attachment from stored bytes. Reads validate bounds, hash, MIME, canonical schema and embedded run/task/attempt/profile/base/goal identity, independently of mutable run result projection. Legacy runs remain empty; no backfill.

It does not allocate, prepare, prompt, poll events, reactivate model/tool work, or downgrade uncertain evidence. A known archive failure unexpectedly reporting running remains quarantined.
