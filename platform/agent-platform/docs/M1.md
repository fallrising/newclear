# M1：可持久化的任務工作台

本文件保留 M1 交付時的範圍與驗收；目前開發進度與真實 runtime 啟動見 [M2](M2.md)。

M1 已提供單 operator 的登入 → 建立任務 → PostgreSQL queue → 獨立 worker → 持久事件 → React 工作台流程。AT-01 與實際 HTTP 串流驗收通過；這一版只使用明確標示的 **fake adapters**，沒有把 M0 probe 直接當作平台的真實 runtime adapter。下一個切片是 M2。

## 已實作的邊界

- FastAPI：session、project、immutable profile revision、task／run detail、明確 retry、runtime 狀態與 SSE。登入後可讀 `/api/v1/openapi.json`。
- PostgreSQL：版本化 migration、checksum guard、單一 operator、hashed session、原子 task/run/job/command/message/event、每 task 一個非終態 run、每 run event counter、來源 event 去重、sandbox binding／reservation 與 fake operation ledger。
- Worker：獨立程序，`FOR UPDATE SKIP LOCKED` 取工作；transaction 內保留最多四個 fake slots。每階段比對 owner／generation／lease；lease 過期改為 interrupted，保留 reservation，不重送 prompt 或自動另建環境。
- Fake agent／sandbox：固定 fixture、可 inspect、穩定 operation ID、可重播的來源事件。`backend_cursor` 與平台 `seq` 分別保存。Result 先存入 DB 才 succeeded，明確標示程式驗證未執行；fake release 的 observed state 確認後才歸還 slot。
- React／TypeScript：登入、任務清單／分頁、建立任務、執行歷史、活動與結果、project／profile 建立。Server state 用 query cache，SSE 以已接收 cursor 重連，event ID 去重。輸出以文字顯示；不 render 任意 HTML。
- root path-scoped CI：M0 checks 保留，新增 PostgreSQL integration 與 Web checks/build。沒有 deploy／release／publish 或 runtime credentials。

來源檔位於 `src/agent_platform/`、`src/agent_platform/migrations/`、`web/`；既有 `agent_platform_m0` 保留原本保守回報語意。

## 本機執行

需要 Python 3.12、Node **24.18.0**、Docker／Compose。Python 完整依賴與 hashes 在 `requirements.lock`，Web 在 `web/package-lock.json`。PostgreSQL 固定為 18.6 Alpine 的 manifest digest；主機不需要另外安裝 PostgreSQL。

```bash
cd platform/agent-platform
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --require-hashes -r requirements.lock
python -m pip install --no-deps -e .
npm --prefix web ci
cp .env.example .env
chmod 600 .env
```

在 `.env` 將兩個 password placeholder 替換成同一個隨機 URL-safe database password。`.env` 不提交，operator password 與 database password 分開。然後：

```bash
set -a
. ./.env
set +a
docker compose -f compose.m1.yml up -d --wait
agent-platform migrate
agent-platform bootstrap --username operator
```

Bootstrap 在 terminal 隱藏輸入並確認密碼（至少 12 字元），只允許建立第一個 operator，不會覆寫既有帳號。非互動環境可用 `--password-file` 指向 repo 外的 0600 檔案；沒有預設密碼或公開註冊 API。

開三個 terminal；API／worker terminal 都先啟用 `.venv` 並載入 `.env`：

```bash
# Terminal 1
agent-platform api --host 127.0.0.1 --port 8000
# Terminal 2
agent-platform worker
# Terminal 3
npm --prefix web run dev
```

開啟 `http://127.0.0.1:5173`，登入後先新增 project 與 Agent 設定，再提交任務。Repository URL 是 HTTPS metadata；base commit 必須是完整 40／64 字元 SHA。M1 保存這些輸入，尚未 clone／驗證遠端 commit 或修改 repository。

`APP_ORIGIN` 必須完全匹配瀏覽器 origin。HTTP 僅在 `APP_INSECURE_LOCAL=1` 且 origin 為 loopback 時允許。API 預設 HTTPS／Secure cookie；正式 TLS reverse proxy 設定與部署屬 M4。

也可先 build，再由 API 同 origin 提供 UI：

```bash
npm --prefix web run build
APP_ORIGIN=http://127.0.0.1:8000 agent-platform api --web-dist web/dist
```

以上仍使用 `.env` 的 loopback-only HTTP opt-in。結束時停止 API／worker／Vite；`docker compose -f compose.m1.yml down` 停止 database 並保留 volume。`down -v` 會刪除開發資料，只有確定要丟棄資料時使用。

## HTTP 與重播

所有 mutation 都驗證 exact `Origin` 與 session-bound CSRF token。`GET /api/v1/session` 提供 CSRF token；login 也需要 pre-login CSRF，成功後輪替 session／CSRF。Session cookie 是 HttpOnly／SameSite=Strict，HTTPS 時使用 `__Host-` 與 Secure，DB 只保存 token hash。登出／到期後既有 SSE 也會停止。登入錯誤不回顯密碼，失敗嘗試有 DB-backed rate limit。

Project／profile／task／retry 要求 `Idempotency-Key`。同 operator、route、key、相同 canonical payload 回原始 status／body／Location；不同 payload 回 `409 idempotency_conflict`。Task、第一個 queued run、job、command、goal message 與初始事件在同一 transaction；其中任一失敗整筆 rollback。Retry 要求 latest run 的 `expected_state_version` 且既有 run 已 terminal。

前端在同一份表單的回應遺失／網路錯誤後保留 command key 和內容；同時送出的相同請求合併，避免 double click 建立多份工作。重新載入分頁後應先查看已保存的任務列表；這一版沒有跨分頁的 pending-command outbox。

`GET /api/v1/runs/{id}/events?after_seq=N` 回 durable replay → live。`Last-Event-ID` 與 query cursor 取較大值，讀取每次都從 committed rows 接續，不以 pubsub 補 replay/live 接縫。`follow=false` 提供有限 replay，方便 CLI／測試。Cursor 早於 `event_floor` 回 410，工作台重新讀取 snapshot 並告知歷史範圍已變更；超前 cursor 回 422。M1 沒有啟用 retention GC。

## 驗收

```bash
make platform-check
make web-check
```

`platform-check` 執行原有 45 tests、Ruff lint／format，以及 21 個 M1 tests。沒有 `TEST_DATABASE_URL` 時，測試 runner 以隨機 password、loopback 隨機 port 與 tmpfs 建立專屬 PostgreSQL，完成或失敗都核對 ownership label 後移除。CI 使用獨立 service database；integration suite 要求 database 名稱為 `agent_platform_test`，會清空其測試資料，不能指向開發或正式 database。

`web-check` 執行 TypeScript、Prettier、12 個 Vitest／jsdom tests 與 production build。已執行結果與來源 hashes 見 [M1 evidence](evidence/m1-2026-09-21.json)。主要 cases：

| 驗收 | 已執行證據 |
| --- | --- |
| AT-01 | 八個並行相同 create 僅一份 task/run/job；同 key 不同 payload 409；六個不同 key 分別建立；失敗整筆 rollback；並行 retry 只有一個成功；DB partial unique index 直接拒絕第二個 active run |
| Login | bootstrap 不覆寫；password hashing、session hash、CSRF／Origin、Secure cookie、到期／logout、rate limit、validation 不洩露 password |
| Durable work | API instance 重建後可讀；獨立 worker process 完成同一個 job；prompt operation 只有一次；結果與事件保存在 PostgreSQL |
| SSE | 真正 TCP/HTTP 連線先讀 queued，再讀 worker commit 的 live event；斷線按 cursor 接續；logout 撤銷既有 stream；來源重播不增加 side effects |
| Fake capacity／fencing | 最多四個 reservation，第五個 queued；確認 fake cleanup 後歸還；expired lease 保留 capacity，舊 worker mutation 被拒 |
| UI | 登入／建立／讀活動／登出、回應遺失保留表單和 key、UTF-8／CRLF streaming、event ID 去重、未受信任 HTML 顯示為文字、服務錯誤可重試 |

API integration 與 HTTP 測試使用真實 PostgreSQL；UI 使用 jsdom component tests。這不是實際瀏覽器 E2E／視覺 QA，也不是 M2 的 100-event browser／雙真實 VM 驗收。

## 後續邊界

M2 才接入已通過 M0 的真實 Cocoon／OpenHands adapters、repository checkout、並行工作台與 diff。M3 補齊 recovery／lease heartbeat／approval／pause／cancel／run budget／egress 的完整故障驗收；M4 補 artifact store、export、backup／GC 與部署。M1 不提供任意 host exec、VM shell、provider key 或 GitHub write credential；不宣告真實 agent 任務已可執行。

`approvals`、`usage_entries`、`artifacts` 與 `export_operations` 仍是 SDD logical schema，尚未遷移實作。當前 fake-only profile constraint 在 M2 以新 migration 擴充，已發布的 migration 不覆寫。Lease 過期的 run 需要後續受控對帳能力，M1 不會自動恢復或回收其未知 reservation。

實作依據：PostgreSQL 的 [SKIP LOCKED](https://www.postgresql.org/docs/18/sql-select.html) 用於 queue admission；[Psycopg pool transaction](https://www.psycopg.org/psycopg3/docs/advanced/pool.html) 管理 commit／rollback；[FastAPI StreamingResponse](https://fastapi.tiangolo.com/advanced/custom-response/#streamingresponse) 傳送已持久化事件。
