# Warp 官方介面截圖

本目錄保存 2026-10-04 從 Warp 英文官方文件取得的五張公開產品截圖，供相鄰[功能手冊](../README.md)逐圖評論與設計比較。

- 保留下載時的原始 WebP bytes，未裁切、重畫、翻譯圖內文字或加入合成 UI。
- 每張的原始網址、出處頁面、尺寸、檔案大小與 SHA-256 見 [assets.json](../assets.json)。
- 圖片呈現的是官方文件的示範介面，不是本專案自行登入或執行 Warp 的驗收證據。
- `schedules.webp` 是空清單；`integrations.webp` 與環境表單含較早版本的用語。文字解說以手冊列出的查核日文件為準，沒有把更新後功能偽裝成圖片中已出現的按鈕。
- 第三方圖片、商標及 UI 的權利仍屬原權利人；本 repository 的 MIT 授權不重新授權這些素材。本次未確認另有可涵蓋圖片再利用的開源授權。
