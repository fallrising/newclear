# Public API and Error Drift

The crate exports only typed configuration/path-policy values, `CredentialScope`,
`CredentialScopeLease`, the three-value `CodexCommand` enum, and a non-extensible
`CodexInvocation`. Public errors contain policy categories and source errors without configured
paths, arbitrary environment values, credential bytes, or auth-cache contents. Public methods carry
the `CU-AUTH-P0-02` rustdoc marker.

# Security and Recovery Review

The implementation revalidates mutable paths before lease acquisition and invocation projection,
rejects repository ancestry for both executable and directories, opens the lease with `O_NOFOLLOW`
and `O_CLOEXEC`, verifies owner/mode/type/link count from the opened descriptor, and uses
nonblocking `flock`. It never opens `auth.json` or starts the executable. Dropping the lock cannot
change or interpret a T002B ledger.

# Fresh Review Findings

The fresh reviewer independently mapped every clause to code and tests and found no correctness,
feasibility, public-API/error, atomicity, TOCTOU, secret-leakage, fixed-argv, or test-coverage
blocker. It confirmed that lease safety is checked from the opened descriptor and that path-based
residual races are consistent with the explicitly trusted single-operator host.

Non-blocking observations:

- Filesystem wrong-owner setup requires elevated CI privileges, so the policy branch is covered by
  a pure unit test while the public symlink branch has a filesystem test.
- Non-Linux fields are irrelevant to the declared Linux P0.
- T010 remains a task-graph prerequisite but its repository-relative value types are intentionally
  not used for administrator-owned absolute host paths.
