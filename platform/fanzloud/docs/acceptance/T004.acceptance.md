# Scope

- T004A / CU-CLOUD-P0-01 / C+F / E2 trusted submit, status, and list runner.
- T004A1 / CU-CLOUD-P0-01 / E2 prompt-free recovery composition bridge.
- T004B / CU-AGT-P0-02 / C+D / E2 provider task lifecycle.
- T004C / CU-CLOUD-P0-02 / D+F / E0 provider-managed diff retrieval.

TD §9.3 requires the E2 and E0 boundaries to remain independently specified and accepted. The
parent owns their composition and no additional production module.

# Composition Evidence

The accepted T002A scope and one private `CommandSpec` path enforce the administrator executable,
cleared environment, only `CODEX_HOME`, private non-repository cwd, null stdin, non-TTY pipes,
bounded continued draining, process group, parent-death binding, deadlines, termination grace, and
direct-child reap for every native T004 command.

T003 remains the only argv authority. Prompt bytes can enter only the fixed one-attempt Cloud exec
argv. Status, list, diff, ledgers, errors, and debug output cannot contain a prompt. No public
surface accepts an executable, argv extension, environment map, local path, repository URL, shell,
checkout, hook, artifact destination, retry callback, `cloud apply`, or local `codex exec`.

T004A records and reconciles non-idempotent submit progress. T004A1 can only observe or explicitly
terminalize the exact lower operation without another command. T004B requires lower terminalization
before the local lifecycle permits another explicit operation. T004C can mint authority only for
the current Ready/Applied lifecycle and revalidates matching lower `TaskRecorded`/`TaskAdopted`
provenance under the same held scope lease. The E0 diff read never gains E2 retry or lifecycle
mutation authority.

The diagnostic boundary composes intentionally: T004A submit/status/list may install and revalidate
the pinned `error.log/` directory sentinel, while Ready/Applied provenance lets T004C require and
validate the existing sentinel without repair-on-read. The private working directory and
provider-owned credential state are never published.
