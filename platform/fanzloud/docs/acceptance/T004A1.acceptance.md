# Scope

CU-CLOUD-P0-01 only: a crate-private, prompt-free recovery bridge over the accepted T004A durable
submit ledger. The bridge observes one caller-created operation, durably terminalizes an explicitly
adopted or abandoned unknown operation, and never selects a candidate, authenticates a decision,
executes a Cloud command, or exposes public retry authority.

# Compatibility, Security, and Recovery Review

The public T004A runner surface remains unchanged. The new observation and resolution types and
methods are crate-private and are not re-exported. `TaskAdopted` and `ExplicitlyAbandoned` extend
the version-1 ledger transition graph without changing its path, size/history bounds, file mode,
ownership, single-link, no-follow, atomic replacement, or directory-sync policy.

Observation first applies the accepted crash classification. Resolution requires the exact current
operation and durable reconciliation evidence; adoption additionally requires the exact latest
candidate. Exact terminal replay performs no write, conflicting resolution leaves the ledger
unchanged, and only an explicit later operation ID can execute another submit. Errors and debug
output contain safe categories and operation IDs, never task candidates, prompts, raw output,
paths, or credentials.
