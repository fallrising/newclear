# Public API and Compatibility Review

The public surface is limited to validated/redacted administrator bootstrap and public-origin
values, bounded HTTP configuration, the control-plane composition, its router, and typed shutdown
error/category. Lower fake ports, monotonic clock, entropy, session leases, request admissions,
idempotency registry, raw transport types, and all route bodies remain crate-private.

The runnable binary constructs listener, credential paths, provider environment/branch, bootstrap
secret, and public origin only from administrator process configuration. No HTTP field can select
an executable, argv, repository path, Codex home, provider token, environment, branch, checkout,
apply operation, or artifact destination.

The HTTP stack added no generic backend abstraction and did not change accepted T002, T004, or
T005A public APIs. Serde and thiserror are pinned to compatible existing proc-macro generations;
`cargo deny` reports no advisory, ban, license, or source violation.

# Authentication, Idempotency, and Shutdown Review

Bootstrap validation compares the complete 128-byte padded representation and length accumulator.
Cookie lookup compares all 43 bytes for every candidate slot or one dummy slot. Test-only work
observations exercise the production loops and prove exactly 128/43 comparison iterations for
matching, malformed/short, first-mismatch, and last-mismatch inputs.

Every successfully cookie-authenticated request immediately owns one application-session lease and
one process-lifecycle admission before body reading. Mutation work adds a detached-worker share, so
request disconnect drops only the HTTP waiter. The exact same request/key joins the in-flight or
completed entry and lower work executes once.

Logout marks only the captured application session invalid. Its completed idempotency tombstone
remains until every request already authenticated against that session has drained, then both the
session and tombstone are removed. A deterministic gated-body race proves that a delayed concurrent
same-key logout joins the first owner, both responses are exact 204s, owner execution count is one,
and later requests fail authentication.

The first shutdown call atomically changes admission to draining, waits for handler and detached
worker leases, then calls session cleanup and login cleanup once before clearing both registries.
Concurrent shutdown callers join the same terminal result. Late bootstrap and protected requests
return the fixed safe 503 without lower work.

# Bounds, Errors, and Redaction Review

The router enforces one exact header value where required, a 256-byte value ceiling, exact JSON
media rules, zero-body routes, a 40-KiB body ceiling, deny-unknown/duplicate JSON fields, strong
non-nil values, and the lower 32-KiB prompt bound. Malformed and nil recovery UUIDs are explicitly
classified as 422 `invalid_value`, while structural JSON failures remain `invalid_request`.

Table-driven assertions cover every `LoginBrokerError`, every non-nested
`P0SessionErrorCategory`, every `CloudLifecycleErrorCategory`, and every
`CloudDiffReadErrorCategory`, including exact status, stable code, fixed message, allowed operation
correlation, JSON field count, and source redaction. Bootstrap/cookie/device-code/prompt/diff/raw
provider/path canaries are absent from debug output and every non-secret response.
