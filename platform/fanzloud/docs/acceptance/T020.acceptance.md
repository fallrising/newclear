# Scope

T020's E0 domain boundary: the version-1 semantic session-event schema, immutable deterministic
session reducer and projection, and total durable/ephemeral runtime-event classification. Event
append, replay storage, transactions, snapshots, actors, transport, and provider behavior remain
outside this acceptance.

# Fresh Review

A fresh, read-only Cursor Agent review independently read the normative documents, implementation,
tests, manifests, traceability, and handoff. It returned `T020 IMPLEMENTATION ACCEPTED` with no
blocking correctness, invariant, security, E0, API, non-scope, or test-completeness finding.

The review's non-blocking observations were:

- non-monotonic `occurred_at` assignment has no dedicated fixture;
- illegal-transition coverage is representative per source state rather than the full Cartesian
  state/event matrix;
- the denied approval decision appears mainly in property/E0 paths; and
- `NewDomainEvent` has no separate serde round-trip beyond the envelope/payload schema locks.

These observations do not weaken a normative clause and are not prerequisites for T030.

# Security, Atomicity, and Recovery

The reducer rejects cross-stream, schema, sequence, transition, turn, and approval confusion before
returning a new value. It carries no arbitrary prompt, diff, provider, credential, path, or tool
content. T020 is pure E0: it owns no side effect, writer, retry, crash recovery, or persisted state.
Those concerns remain explicitly assigned to later tasks.

# Decision

Accepted. Every T020 contract clause has executable or inspection evidence, the test-first history
is recorded, local gates and hosted CI pass, and a fresh-context document-driven review found no
