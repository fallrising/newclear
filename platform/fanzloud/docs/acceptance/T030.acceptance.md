# Timestamp Compatibility Discovery

The C extrema oracle exposed an inherited canonical extended-year timestamp readback failure.
Normal append rolls back that error before COMMIT. Accepted ADR-0006 repairs only decoding:
strict legacy RFC3339 first; fallback only by byte-exact existing Nanos/UTC-Z encoding equality.
The supplementary named regression first failed at canonical MIN_UTC append readback, then
passed extrema/signed-year/leap/legacy-offset/noncanonical-fault oracles through public
append/replay/save/load/reopen. Stored schema/version/format, dependencies and domain APIs stay
unchanged. Earlier acceptance records are preserved as historical, narrower evidence.
