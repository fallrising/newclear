# Scope

T030A's `CU-EVT-01` boundary: private version-1 SQLite initialization and E1 atomic
expected-sequence event append. Public replay, snapshot load/save, reducer semantics, session
actors, command idempotency, migrations, backup, encryption, and network storage remain outside
this acceptance.

# Fresh Reviews

A fresh, read-only Cursor Agent contract review independently inspected the normative documents,
public boundary, implementation, tests, and evidence. Its first pass blocked acceptance because
the payload-bound and foreign-owner tests did not execute the claimed defensive branches. Those
tests were repaired. The fresh rerun returned `CONTRACT ACCEPTED` with no remaining blocker.

A separate read-only Grok transaction/security review inspected the production transaction,
schema, sequence codec, error, async, and path-policy boundaries plus their tests. It returned
`SECURITY ACCEPTED` with no blocker.

The reviews recorded three non-blocking limitations:

- foreign ownership is proved through the production owner-policy helper rather than requiring a
  second operating-system user in CI;
- raw SQLite diagnostics are discarded by the typed error design; and
- malicious same-UID path replacement after validation is an explicit non-guarantee that would
  require descriptor-relative deployment integration.

These limitations do not contradict a T030A clause and remain outside the accepted P1 child.

# Security, Atomicity, and Recovery

The store accepts only an administrator-selected private local path, fixed SQL, bound parameters,
bounded batches, and the closed T020 event schema. `BEGIN IMMEDIATE` acquires the writer boundary
before checking the committed high-water. Commit is the only durable visibility point; validation,
conflict, serialization, constraint, busy, cancellation, and crash paths cannot claim or expose a
partial successful batch. Retrying an unobserved attempt is allowed only with the same expected
sequence, followed by replay and re-decision on conflict.

# Decision

Accepted. Every T030A contract clause has executable or inspection evidence, the test-first
history is recorded, all local gates and hosted CI pass, and independent fresh contract and
security reviews found no remaining blocker. T030B may now specify bounded E0 replay over the
accepted row codec. T030C/T030D remain separate; T030D is still blocked by the snapshot-save
atomicity gap.
