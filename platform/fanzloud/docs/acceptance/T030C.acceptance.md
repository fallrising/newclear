# Implemented Boundary

`SqliteEventStore::load_snapshot(SessionId)` implements CU-EVT-03 E0 from
[SPEC-T030C](../specs/SPEC-T030C-sqlite-snapshot-load.md). It opens read-only without create flags,
pins one deferred transaction before identity/key/head/cache reads, verifies exact v2 identity
and structural keys, and maps only private `InvalidSnapshotCache` errors to None. Eligible
S<=4096 may be stale behind any full-u64 H; the same transaction verifies1..S through the accepted
bounded event decoder/reducer. Canonical96-byte equality compares all projection fields and the
result wraps the newly replayed projection. No cache bytes restore domain state; no DDL/DML,
repair, migration, recreation, internal retry, dependency or public domain import was added.

Per-handle load phase hooks are `cfg(test)` only. They drive public-future worker faults,
cancellation and pinned multi-page concurrency; production cannot select faults or SQL. Save's
transaction/arbitration/provenance rules are preserved. D's source phase guard now permits
public load after accepted C design, retaining historical D acceptance unchanged. Snapshot,
constant and safe error rustdoc projections identify CU-EVT-03 where applicable.
