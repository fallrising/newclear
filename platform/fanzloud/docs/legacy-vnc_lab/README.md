# vnc_lab — sandbox requirements（已退役）

`vnc_lab` 是一組 Docker/noVNC 桌面 image，整合 Cursor、AI CLI、Warp 與遠端開發環境。
它驗證了 `fanzloud` 需要的 sandbox 需求，但 image 本身視為實驗品。

這裡保留部署摘要、子網域相容性報告與各 image 的需求說明。
**實作不要直接沿用**——隔離邊界與 credential boundary 需要在 fanzloud 中重寫。
