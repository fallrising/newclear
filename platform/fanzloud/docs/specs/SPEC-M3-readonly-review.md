Rejected/failed/unknown review never silently resets counters.

Derive fixed original base/project/profile and goal plus bounded review reasons from trusted records; fresh isolated workspace. Persist `run.rework_context` with `root_writer_run_id,review_run_id,candidate_sha256`; purpose coding. Second review must use that successful rework writer and opposite vendor. Generic task-run retry must not bypass linked lineage. New unrelated tasks are separate explicit work, never implicit retries.
