# Outcome

Provide the Linux P0 credential scope that validates the administrator-owned Codex paths and native
executable, exposes only fixed command policy, and serializes one operator scope with an E1 file
lease.

# Inputs

- TD §§1.6–1.7, 2.2–2.3, 7.4, 8.2–8.10, 11.3 P14, 14, and 15.0
- ADR-0002 §Credential boundary
- T001 and T010 acceptance

# Deliverables

- `codebox-agent-codex` crate and explicit workspace membership.
- Validated Linux-only `CredentialScope` and typed configuration errors.
- Mode, owner, symlink, overlap, and repository-ancestry checks.
- Exact native executable plus fixed argv and cleared-environment policy.
- Cross-process non-blocking RAII lease with mode-`0600` metadata.
- Contract, concurrency, permission, and secret-canary tests.

# Non-scope

- Starting Codex, parsing provider output, device-code values, login ledger, reconciliation, HTTP,
  browser state, repository checkout, and Codex Cloud tasks.

# Invariants

- Credential material is never read or projected.
- No browser or repository value selects a path, executable, argv item, or environment entry.
- At most one lease owns an operator scope at a time.
- Checked failure does not mutate `CODEX_HOME`.
