# Outcome

Run and supervise the pinned native Codex CLI device-login lifecycle inside an accepted credential
scope, exposing only bounded verification instructions and normalized login status.

# Inputs

- TD §§1.6–1.7, 2.2–2.3, 7.4, 8.2–8.10, 11.3 P14, 14, and 15.0
- ADR-0002
- Accepted T002A credential scope
- Codex CLI `0.145.0` fixtures

# Deliverables

- Fixed version, login-status, and device-login process adapter.
- Exact pinned fixture parser and typed redacted projections.
- Durable versioned login ledger.
- Background bounded pipe draining, timeout, process-group cancellation, parent-death binding, and
  crash reconciliation.
- Fake-CLI lifecycle, output, fault, recovery, and P14 regression tests.

# Non-scope

- Scope/path validation owned by T002A, browser API, Codex Cloud task execution, repository
  checkout, prompts, API-key login, arbitrary issuer/client ID, and multi-user tenancy.

# Invariants

- Inconclusive preflight status fails closed before destructive device login.
- Unknown process or provider outcome is never retried automatically.
- A broker crash does not leave a runnable unsupervised login child.
- Raw CLI output and credential material never enter errors, ledger, events, or artifacts.
