# Outcome

Provide a side-effect-free, version-pinned contract boundary for the exact Codex Cloud CLI commands
and outputs that later orchestration may execute.

# Inputs

- TD §§1.6–1.7, 2.2–2.3, 5.1, 8.2–8.10, 9.2–9.6, 11.3 P14–P15, 14, and 15.0
- ADR-0002 §First execution interface
- Accepted T001 and T010
- Official Codex CLI `rust-v0.145.0` cloud-task source and local `--help` output

# Deliverables

- Strong bounded environment, branch, task-ID, prompt, status, list-page, and diff projection types.
- Non-extensible version, exec, status, list, and diff invocation policies.
- Exact pinned decoders for source-derived fixtures with bounded redacted errors.
- Test skeletons and implementation for malformed output, output bounds, argv separation, status
  exit mapping, pagination, diff bounds, version drift, and P14/P15 regressions.

# Non-scope

Starting a process, reading credentials, submitting or polling a real task, durable side-effect
records, retries, reconciliation, cancellation, session events, `AgentBackend`, repository checkout,
`cloud apply`, and local diff application.

# Invariants

- This E0 task performs no provider or filesystem side effect.
- Prompt, environment, branch, task ID, and cursor are distinct validated values and never shell
  fragments.
- Unknown version, origin, schema, status, exit mapping, control character, or oversized output
  fails closed without returning raw output.
- No command can select `cloud apply`, `codex exec`, a shell, or repository-controlled execution.

or credential is required for T003.
