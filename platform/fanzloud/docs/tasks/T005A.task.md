# Outcome

Provide one process-lifetime, single-writer P0 session over the accepted T004 orchestrator with one
active turn, rate-limited status monitoring, explicit-only cancellation/recovery, and bounded
ordered event replay/fanout.

# Inputs

- TD §§1.7, 2.3, 4.2, 4.4, 4.7, 8–10, 14, and 15.0
- ADR-0002, ADR-0003, and ADR-0004
- Accepted T004 lifecycle, recovery, cancellation, and diff contracts

# Deliverables

- New focused `codebox-session-runtime` crate
- Typed P0 session commands, snapshots, versioned events, subscriptions, and redacted errors
- Deterministic fake-Cloud tests plus accepted T004 composition tests

# Non-scope

- HTTP, WebSocket framing, authentication, or browser policy
- Generic `AgentBackend`, P1 canonical events, persistent event store, or crash replay
- Recovery-policy decisions, provider cancellation claims, diff persistence/application, or
  arbitrary polling/command authority

# Invariants

- At most one mutating turn is active.
- A lower lifecycle is emitted only after T004 durably returns it.
- Unknown submit is never automatically retried.
- Disconnect/drop affects only a subscriber.
- Prompts, diffs, codes, credentials, raw output, and internal paths never enter session events.
