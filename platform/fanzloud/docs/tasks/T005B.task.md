# Outcome

Expose the exact ADR-0004 P0 login/session endpoints through one private, single-operator,
cookie-authenticated JSON trust boundary with process-instance-bound idempotency and redacted typed
errors.

# Inputs

ADR-0004, SPEC-T005B, accepted T002 login broker, and accepted T005A session runtime.

# Deliverables

- Control-plane router and administrator configuration
- Bootstrap exchange, secure cookie session, Origin enforcement, bounded JSON, endpoint-specific
  typed mappings, and in-flight/completed idempotency
- Runnable control-plane binary configuration without browser-selected paths/environment/branch

# Non-scope

WebSocket replay, HTML/JavaScript UI, public/multi-user auth, P1 REST, provider credentials,
repository checkout, or arbitrary command/configuration input.

# Invariants

INV-004, INV-006, INV-007, INV-010, and INV-012 remain true across every HTTP exit.

# Dependency Evidence

T005A is Accepted in `ACCEPT-T005A`. Three T005B-specific fresh reviews repaired seven contract
gaps and two residual contradictions; the final read-only review returned `DESIGN ACCEPTED`.
`ACCEPT-T005B` records the implementation, regression repairs, complete validation, and final
fresh-context read-only acceptance.

# Decomposition

CU-API-P0-01 remains one task with an endpoint atomicity/error table. WebSocket transport is T005C.

Contract tests cover every route, auth/cookie/Origin, deterministic expiry/capacity, constant-work
comparison, bounds, same-key replay and conflict, stale-instance rejection, recovery
acknowledgement, shutdown cleanup, verification-code containment, redaction, and no arbitrary
provider/host authority. All 19 names are substantive, the package passed ten consecutive final

# Risks and Gaps

Auth/session tokens and device codes require canary tests proving absence from logs, events, debug
output, and non-login responses. The accepted canary suite covers those values plus prompts, diffs,
raw provider text, credential markers, and internal paths. T005C remains responsible for preserving
the same containment across WebSocket frames and close reasons.
