# Outcome

Expose authenticated, bounded, version-1 replay-then-live WebSocket frames over the accepted T005A
subscription contract without mutating session/provider state.

# Inputs

ADR-0004, SPEC-T005C, accepted T005A subscription semantics, and accepted T005B authentication.

# Deliverables

- Exact WebSocket subscribe/frame/error schema
- Race-free replay/snapshot/live handoff
- Handshake deadline, cursor/gap checks, subscriber caps, lag cleanup, and disconnect independence

# Non-scope

Session ordering authority, mutating commands, polling, crash-durable replay, diff/prompt/code
frames, generic event protocols, or browser UI.

# Invariants

Stream connection, failure, lag, and disconnect never cancel or otherwise mutate a turn.

# Dependency Evidence

T005B is Accepted in `ACCEPT-T005B`; its application-session lease and exact cookie/Origin
authentication are the only HTTP authority this transport may reuse.
The T005C-specific audit repaired frame/error/close schemas, upgrade normalization,
open-connection revocation, timer/control behavior, and deterministic private seams. The final
fresh-context read-only review returned `DESIGN ACCEPTED`.

# Decomposition

T005A owns event ordering/retention/fanout. T005C owns only authenticated WebSocket transport.

# Machine Acceptance

Contract/property/integration tests cover replay order, no-gap handoff, reconnect deduplication,
future/gap cursor errors, invalid frames, auth/Origin, subscriber lag, disconnect cleanup,
redaction, and chunk/frame boundary behavior. They also cover normalized safe upgrade rejection,
exact error/close ordering, open-connection logout/monotonic expiry, server shutdown grace, and one
concrete loopback composition with the accepted T005A subscription adapter.

# Required Documentation Updates

Update SPEC-T005C, this task, traceability, HANDOFF, and `ACCEPT-T005C`.

# Risks and Gaps

Resolved. Replay/live, slow-consumer, blocked-admission, expiry/logout, shutdown/write, and cleanup
tests pass with ten internal repetitions for tests 8–11 and ten external suite runs. The final
fresh-context repaired-tree review returned `IMPLEMENTATION ACCEPTED`; see `ACCEPT-T005C`.
