# Outcome

Coordinate the independently accepted SQLite append, replay, snapshot-load, and snapshot-save
boundaries into the complete TD §4.6 P1 event-store adapter.

# Inputs

- TD §§4.4–4.6, 8.1–8.10, 9.3, 14, 15.1–15.2, and 16.2
- Accepted T020 versioned event schema and reducer

# Deliverables

- Accepted T030A append, T030B replay, T030C snapshot load, and T030D snapshot save children.
- One composition review proving the children share one compatible versioned SQLite schema.
- Parent acceptance, traceability, and handoff evidence.

# Non-scope

Session actors, command dispatch, side-effect ledgers, REST/WebSocket delivery, reconciler behavior,
backup orchestration, encryption at rest, PostgreSQL, or event-schema upcasting.

# Invariants

- Durable event sequences remain unique, strictly increasing, contiguous, and gap-free per stream.
- Append remains all-or-none and a losing expected-sequence writer must re-read and re-decide.
- Replay returns immutable durable events in sequence order without mutation.
- Snapshots remain discardable caches and never replace durable event history as source of truth.

# Dependency Evidence

T020 is Accepted. The T030 seed is decomposed because TD §9.3 requires distinct tasks for its E1
append, E0 replay, E0 snapshot-load, and E1 snapshot-save atomicity models (ADR-0005 resolves the latter design).

# Machine Acceptance

All four child acceptance reports, their focused tests, workspace gates, database restart tests,
and a fresh parent composition review must pass. The test-first composition target exercises:

- `event_store_snapshot_composition_survives_restart`: public append/replay/save/load share exact
  v2 schema; a saved prefix remains usable after append and restart, while caller-owned replay
  reconstructs the full current projection without importing stored fields.
- `event_store_snapshot_miss_keeps_durable_replay_authoritative`: malformed disposable values
  produce load misses without changing cache/history; full replay remains exact and authoritative.
- `event_store_snapshot_failure_preserves_append_replay_and_other_streams`: expected-head/save
  conflicts and structural/history load failures leave existing events and other streams unchanged;
  valid independent streams retain A/B/C/D behavior.

These are integration projections of accepted child contracts, not new production boundaries.
All three pass substantively; [ACCEPT-T030](../acceptance/T030.acceptance.md) records independent
composition acceptance and the complete current gates.

# Required Documentation Updates
