# Outcome

Load an absent or present versioned session snapshot cache through an E0 bounded-resource boundary.

# Inputs

TD §4.6, accepted T030A/T030D schema and snapshot type.

# Deliverables

`load_snapshot` with absent, present, stale, corrupt, restart, bound, and no-mutation evidence.

# Non-scope

Snapshot production, saving, public reducer restore/import, history repair/deletion, or cache cleanup.
Internal prefix replay for persisted provenance is required by the accepted T030D design;
it is not a replacement for public A/B replay or caller-owned suffix reduction.

# Invariants

Load never mutates durable history, and a snapshot is never represented as source of truth.

# Dependency Evidence

The [ADR-0005](../adr/ADR-0005-snapshot-cache-contract.md)/
[SPEC-T030D](../specs/SPEC-T030D-sqlite-snapshot-save.md) codec/trust/schema design is accepted.
T030D runtime is Accepted. [SPEC-T030C](../specs/SPEC-T030C-sqlite-snapshot-load.md) and its
[independent design review](../acceptance/T030C-design.acceptance.md) preceded implementation.
[Runtime acceptance](../acceptance/T030C.acceptance.md) separately accepts public load after
compiling RED, substantive tests, full gates and fresh review. The shared matrix assigns public
load/C assertions here; historical D acceptance does not claim those assertions.

# Decomposition

One E0 `CU-EVT-03` boundary.

# Machine Acceptance

All 19 C obligations, three parent scenarios and the supplementary ADR-0006 timestamp regression
pass in the 99-test store suite. The 295-test workspace, 10 Node tests, separate fake-provider P0
E2E, formatting, Clippy, build, dependency and diff gates passed; fresh independent review accepted
runtime and composition. Exact commands/results are in the runtime acceptance report.

# Risks and Gaps

Accepted design S09/S10 defines absent/corrupt/unsupported cache **values** as miss (structural lookup-key/schema/index/physical
damage remains store error), corrupt observed history as
error, pinned read transaction, verified replayed projection, and cache-sequence budget S<=4096
even behind larger H. No direct import into private reducer/projection is permitted.
The complete E0 SPEC-T030C is Verified with separate design and runtime evidence. Verification
replays the whole prefix and does not accelerate startup; Some proves no suffix validity, and
None proves no history validity. Synthetic Io/Full phase faults are distinguished from actual
Busy, missing-file and process-interruption tests. Automatic rustdoc/spec drift tooling remains
a documented gap; current projections received explicit independent review.
