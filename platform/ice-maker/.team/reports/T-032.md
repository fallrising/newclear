## Summary

Added a loopback-only FastAPI/Uvicorn upload service backed by the accepted
batch coordinator. Each request requires explicit per-file rights, data class,
OCR languages, and declared size; streams bytes into descriptor-pinned numeric
paths; validates actual sizes and signatures; and atomically publishes one
content-addressed batch or nothing. The durable attempt log recovers abandoned
running work on restart, result truth is validated from disk, and a retained
single-process lock plus configured ceiling limits execution to two workers.

The first worker result was rejected as PARTIAL because it had two effective
tests, inferred confirmed rights, used replace-capable directory rename, relied
on path-following state operations, and could preserve stale running state.
