## REWORK 1 — orchestrator findings

Decision: REWORK. Keep the original scope and verification command. Add focused
regression tests first, prove they fail for the expected reasons, then make the
smallest fixes and update the report with honest RED/GREEN output.

- `init` must reject a symlinked `specs` directory or `specs/templates`
  destination before making any write. A temporary repository whose
  `specs/templates` points outside the repository must return nonzero and leave
  the external directory byte-for-byte unchanged.
- `init` must preflight every existing config/template before creating or
  copying anything, so a divergent template/configuration failure does not leave
  partial initialization changes.
- `new` must replace every canonical title placeholder, including
  `<short feature title>` in front matter, and the lifecycle test must assert the
  parsed title equals the supplied title.
- Validate generated staging contents before publication and reject unsafe title
  values that would make the constrained front matter invalid. On every failure,
  no target SDD directory may remain.
- Update safety documentation only if the implemented behavior changes it.

## REASSIGN — Codex Terra

The Luna rework fixed the listed regressions, but the original atomic
no-overwrite criterion is still not met: `os.rename(staging, target)` can replace
a target directory that appears after the final existence check if it is empty.

  primitive never replaces a target which appears between preflight and publish.
- Implement an atomic no-replace publication primitive on the supported Linux

  fail closed with an actionable diagnostic; do not fall back to overwrite-capable
  rename.

  rewrite the report with the added RED/GREEN evidence. Ensure the report ends
