## REWORK 1 — orchestrator evidence

Focused tests pass, but the intake boundary is rejected:

- The accepted Phase 0 classes are `public`, `internal`, `confidential`, and
  `restricted`; the implementation instead accepts `sensitive` and rejects
  `confidential`, breaking downstream policy compatibility.
- Only leaf symlinks are rejected. A source or state root reached through an
  intermediate symlink is followed, and intake uses a stat-then-open sequence
  without `O_NOFOLLOW`/descriptor identity validation.
- Existing manifests are trusted when their parsed `sha256` alone matches.
  Other fields, object type/content, JSON duplicates, rights/class conflicts,
  and symlinked objects are not validated.
- Taxonomy output is a mutable dictionary and intermediate symlink components
  are followed, despite the immutable/canonical input contract.
- Intake accepts binary `P4` although the approved synthetic extractor accepts
  only ASCII `P1`, creating an unusable successful manifest.

Required rework:

- [ ] Use exactly the Phase 0 data classes. Provider eligibility may be true
  only for confirmed, clean `public`/`internal`; `confidential`/`restricted`,
  unconfirmed/denied, or sensitive findings remain local-only.
- [ ] Reject symlinks in every existing component of source/state/taxonomy
  paths. Open the source once with no-follow semantics, validate the descriptor
  is regular and stable, and read bounded bytes from that descriptor.
- [ ] Accept only `%PDF-` and ASCII `P1` inputs supported downstream.
- [ ] Strictly validate duplicate-free existing manifest JSON with exact keys,
  types, values, schema versions, relative object path, and immutable object
  bytes/hash/size/regular-file identity. A renamed duplicate with the same
  rights/class returns the original manifest; conflicting rights/class fails
  rather than silently reusing another decision.
- [ ] Return an immutable taxonomy mapping, validate all path components and
  canonical content, and test caller mutation attempts plus malformed/duplicate
  files.
- [ ] Add focused regressions for intermediate symlinks, forged manifest/object,
  class compatibility, P4 rejection, and no partial unsafe publication. Replace
  the report with exact REWORK evidence and rerun the full suite.
