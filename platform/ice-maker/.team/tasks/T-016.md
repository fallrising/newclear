boundary:

  and creates the target file (`broken_symlink_followed True`). Existing journal,
  WAL, and SHM leaves are not checked either.

  individually bound to citation IDs. Iterable materialization is unbounded.

  caller mutation after construction must have no effect.

  corrupt row/index must fail before proposal output.
- [ ] Bound chunk/conclusion iterables before full materialization. Sanitize
  query and conclusion text consistently. Make related comparisons meaningful
  immutable values, and represent an explicit citation-ID binding for every

  schema/FTS corruption, bounded generators, conclusion safety/citation binding,
