## REWORK 1 — orchestrator evidence

The three happy-path tests and 119-test repository gate pass, but independent
subprocess probes break the stage and provenance contracts:

- Calling `index` immediately after `ingest`, using the manifest hash as the
  claimed extraction ID, succeeds (`index_without_extract_succeeded True`). The
  index command silently reruns extraction instead of consuming persisted
  extraction evidence.
- After indexing manifests A and B in the shared database, proposing for A with
  A's index evidence and a B-only query succeeds and cites B's source hash
  (`cross_manifest_citation_succeeded True`).
- Editing a restricted manifest's `provider_eligible` field to true permits a
  proposal (`forged_manifest_policy_succeeded True`) because the CLI rechecks
  only a small caller-controlled subset rather than the content-derived policy.

Required rework:

- [ ] Persist canonical, immutable extract evidence with a digest-derived
  `extraction_id`; `index` must load and fully validate that exact record and
  must never call extraction or create an extraction cache as a fallback.
- [ ] Bind index evidence to its exact validated chunk IDs/source hash and make
  proposal retrieval incapable of returning any row outside that evidence
  (for example, a per-index database). Revalidate the index evidence digest and
  reject every citation not in the bound set. Include the existing explicit
  per-conclusion citation bindings in CLI output.
- [ ] Reuse the secure source-store validation/read primitives to rederive the
  complete manifest policy from immutable source bytes. Reject forged fields,
  unknown/missing fields, noncanonical/oversized JSON, and any manifest,
  quarantine, extract, index, or proposal path containing a symlink.
- [ ] Publish stage evidence atomically without replacement through checked
  directories; never use unchecked `read_bytes`, `mkdir(parents=True)`, or
  `Path.open` at this trust boundary.
- [ ] Add regressions for all three exact probes, stage-evidence tampering and
  symlinks, cross-manifest empty/mismatched retrieval, explicit citation
  bindings, and state roots under `.git`/tracked knowledge/outside the repo.
  Replace the report and rerun focused/full gates.
