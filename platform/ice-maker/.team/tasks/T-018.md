## REWORK 1 — orchestrator evidence

Focused and full tests pass, but the public value boundary is not yet the
Phase 4 provenance contract:

- `Citation` and grounded `citation_ids` accept values such as `chunk-1`, even
  though every Phase 4 chunk identity is an exact lowercase SHA-256.
- `Note` silently freezes lists/generators despite the task requiring mutable
  inputs to be rejected. Public comparison/report values have no invariant
  checks, and the pairwise report has no bounded-output guard.
- An orphan record omits the source note's citation IDs, and a duplicate found
  only through equal conclusions is still labelled `normalized-text`.
- Contradiction recognition is hard-coded only to `safe/unsafe` and
  `true/false`, with no regression for normalized `claim`/`not claim` evidence.

Required rework:

- [ ] Require exact lowercase SHA-256 source and chunk identities everywhere;
  add drift/malformed regressions using realistic 64-hex fixtures.
- [ ] Reject mutable or one-shot collection inputs at frozen value boundaries;
  validate emitted value invariants and bound report cardinality before
  allocating unbounded pair records.
- [ ] Include exact source-note citation IDs in orphan evidence and report the
  truthful duplicate reason (`normalized-text` or `same-grounded-conclusion`).
- [ ] Support and test deterministic normalized negation contradictions while
  retaining explicit `safe/unsafe` and `true/false` pairs.
- [ ] Refactor long compound lines, rerun focused/full tests, and replace the
  report with exact counts and limitations.
