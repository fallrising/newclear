## REWORK 1 — orchestrator review

The written suite passed 164 tests, but independent probes found the following:

- A complete all-zero snapshot has no violations, so zero success/test/cache
  hit/OCR-confidence rates incorrectly satisfy thresholds intended as minima.
- Directly constructed `LocalEvidence` with commit `x` and artifact `y` reaches
  `DEVELOPMENT_COMPLETE` when its digest is recomputed. Validate every field at
  construction and again at evaluation; bind the actual current Git SHA form.
- A `token` label is accepted. The test appeared green only because the later
  incomplete-snapshot check raised instead. Test unsafe labels in isolation.
- The external gate tuple omits real restore, rotation, telemetry/cost alert,
  and compromise-drill attestations required by SDD-0007.

Add explicit threshold direction (`minimum` or `maximum`) to both configs and
reject direction drift. Add isolated regressions for low-rate violations,
direct-value forgery, unsafe labels, full external gates, oversized/symlinked
configuration, and every frozen/slotted public value. Preserve deterministic
safe violation identities and rerun the original verification.
