# ADR-004 LogQL clean-room 聲明

## 目的

本聲明建立 Prism LogQL 相容實作的來源邊界。所有參與 lexer、parser、IR、planner、executor、測試案例或相容性修正的人員與 agent，都必須在開始實作前閱讀本文件並追加簽署。

## 允許來源

- 公開的 LogQL 語法與使用者文件。
- 公開的 Loki HTTP API 文件與協定描述。
- 對公開服務或獨立測試環境進行黑箱請求後觀察到的輸入、輸出、狀態碼與錯誤類型。
- 由 Prism 貢獻者獨立撰寫、且未衍生自 Loki 原始碼或測試碼的 fixtures。

## 禁止來源

- Loki 的 lexer、parser、planner、executor 或相關原始碼。
- 從 Loki 原始碼、測試碼或其衍生實作複製、翻譯、改寫或機械生成的內容。
- 以直接或間接相依方式匯入 `grafana/loki` 實作。

## 聲明

簽署者聲明：在其簽署範圍內，未閱讀、複製、翻譯或改寫上述禁止來源；所有 LogQL 相關產出僅依據允許來源獨立完成。若工作期間意外接觸禁止來源，簽署者將停止相關實作、記錄暴露範圍，並由未受污染的實作者重新完成受影響內容。

本聲明不代表任何未列名的人員，也不以 agent 的簽署替代未來實作者的個別簽署。
