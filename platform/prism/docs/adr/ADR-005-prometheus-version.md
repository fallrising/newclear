# ADR-005：回報真實相容的 Prometheus 版本

## 狀態

Accepted

## 決策

Prism 的 Prometheus 相容狀態端點回報經驗證的實際相容版本，例如 `2.53.0`，而不是 Prism 自身版本或虛構的未來版本。相容版本升級必須由契約測試證明後才能調整。

## 背景

Grafana 會讀取 Prometheus build information 並依版本啟用或停用查詢與 UI 功能。即使查詢端點本身可用，無法解析或不可信的版本資訊仍可能讓 Grafana 降級功能或誤判能力。

## 理由

- 回報經驗證的相容版本能讓 Grafana 採用符合 Prism 實際能力的行為。
- 將產品版本與協定相容版本分開，可避免兩者的發布節奏互相綁定。
- 版本宣告可成為明確且可測試的相容性承諾。

## 後果

- Prism 必須維護相容性測試矩陣，記錄宣告版本所需的行為。
- Prism 產品版本需透過其他欄位或控制平面端點揭露。
- 不得為了讓 Grafana 顯示更多功能而提高版本字串，除非相關 API 已通過驗證。
- 若不同端點的相容程度不一致，應以不會誇大能力的版本為準並記錄例外。

## 替代方案

### 回報 Prism 產品版本或自訂版本字串

否決。Grafana 可能無法解析，或把它錯當成 Prometheus 功能版本，導致不穩定的功能偵測。

### 省略 build information 端點

否決。這會使 Grafana 無法完成其既有的資料來源健康檢查與能力判斷。
