# ADR-008：服務依賴圖採近似計算

## 狀態

Accepted

## 決策

Prism v1 以同一批次內可觀察到的 parent/child spans 及 client/server 關係近似產生服務依賴圖。系統不承諾跨所有歷史資料做完整且精確的全域 parent join。

## 背景

精確服務依賴圖需要把可能分批、延遲、亂序甚至缺失的 spans 做長時間全域關聯。對單節點且資源受限的 Prism 而言，持續維護這類 join 狀態會增加記憶體、儲存掃描與延遲成本，而遙測資料本身也常因 sampling 而不完整。

## 理由

- 批次內關聯可在有界記憶體和計算時間內完成。
- 服務依賴圖本質上已受 sampling、遺失資料與 instrumentation 品質影響，近似結果仍足以支援拓撲探索。
- 避免在 ingest 或查詢路徑引入無界的跨批次 join 狀態。
- 可先提供穩定、可解釋的結果，再依實際需求新增離線精算模式。

## 後果

- 跨批次或缺少另一端 span 的服務邊可能缺失，邊權重也可能低估。
- API 與 UI 必須把結果標示為近似值，不得暗示完整追蹤覆蓋。
- 演算法需以決定性規則處理重複 span 與同批次多重關係。
- 未來若新增精確模式，必須作為不同能力與成本層級，不可靜默改變 v1 語意。

## 替代方案

### 對全部歷史 spans 執行精確全域 parent join

否決。此方案需要昂貴且可能無界的索引、掃描與狀態維護，仍無法補回 sampling 或遺失的 spans，不符合 v1 資源預算。

### 完全不提供服務依賴圖

否決。即使是明確標示的近似拓撲，仍能為服務探索與故障定位提供實質價值。
