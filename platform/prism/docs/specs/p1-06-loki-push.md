# P1-06: Loki JSON push

## Goal and boundaries

Implement authenticated `POST /loki/api/v1/push` JSON ingestion through the existing P1-03 pipeline and memory SPI. P1-04/P1-05 provide fixed-tenant file-backed bearer, HTTP/TLS, finite read deadlines and drain order. Go 1.27.1, dependency versions, go.sum and public SPI remain unchanged. No Loki source code, AGPL import, LogQL/query, protobuf push, new dependencies, deployment or P1-07. Root owns necessary runtime/config/security/external acceptance in addition to the receiver path from SDD12.

## Wire and trust

Require a single Content-Type application/json (optional charset=utf-8), and absent/identity or gzip Content-Encoding. Unsupported media/encoding returns 415; malformed or ambiguous headers/body return 400; wrong method405/AllowPOST. Authenticate exactly one bounded Bearer header before body reads; constant-time key comparison. Tenant selector headers, if present, must each occur once and exactly equal configured tenant; conflicting/duplicate selectors 400. Missing/wrong/duplicate Authorization 401. Inject trusted tenant context; parsed user labels cannot set reserved identity. Fixed diagnostics never echo credentials, body, metadata or backend errors.

Payload has streams array; each stream has a string-to-string stream label map and values array. Each value is [timestamp-string, line-string, optional flat string-to-string metadata object]. Require structural types, reject nulls/duplicates at every object and unknown structural members; numeric timestamps and nested/nonstring metadata are400 before admission. Empty streams/values are allowed no-op 204. Timestamp conversion and label/resource/severity/trace/span mapping follow existing SDD15 normalizer, including configured clock-skew policy and reserved-label removal. Structural validity is whole-request; valid records may survive semantic timestamp/limit rejections.

## Bounds and lifecycle

One nonblocking slot independent of OTLP/remote_write, held from body read through final normalization/submission and cancellation callback completion. Concurrent capacity 429 Retry-After, Stop 503; Stop starts no goroutines and existing admitted work retains ownership. Cancellation closes request body and joins the callback before releasing the slot. Existing server timeout bounds normal network bodies; SubmitLogs context preserved. Every per-request normalizer is closed.

Compressed and decompressed payload each capped at ingest.max_request_bytes (including unknown ContentLength/chunked input); gzip CRC/truncation/trailing invalid data rejected. Validate UTF8 and JSON syntax/shape before full materialization: bounded depth 16 and aggregate protocol/token elements 100,000, counting object keys/values/arrays/streams/entries/metadata, including empty containers. Count/shape validation must not first allocate the full untrusted graph. Duplicate-key tracking is bounded by that cap. Pass actual decompressed JSON byte length to SubmitLogs, including whitespace; do not reserialize for accounting. Normalization must check cancellation across streams including empty streams, and avoid amplifying shared stream metadata across entries past finite limits. Before materialization, additionally bound projected normalized work: sum of entries times (one plus stream-label count), plus per-entry metadata members, must not exceed 100,000. Project shared label key/value strings per entry plus body/metadata strings and resource/severity duplication against MaxRequestBytes, using overflow-safe arithmetic. Reject expansion over capacity with 413 before any submission, even when a later normalization step would drop fields. All diagnostics are bounded fixed categories.

API: `lokiapi.NewPushReceiver(submitter, lokiapi.PushOptions{Tenant,APIKey,MaxRequestBytes,Normalize,Logger}) (*PushReceiver,error)`. Submitter exposes `SubmitLogs(context.Context, []utm.LogRecord, int64) (ingest.Result,error)`. Receiver has HTTPHandler() and Stop(). Match existing remote_write ownership patterns without refactoring other protocols. Runtime registers exact Loki path; constructor failure stops previous receivers; all receivers stop before pipeline drain/backend close. Only all-in-one/ingest roles expose push.

Add two request-size buffers for the independent one-slot Loki receiver to LogicalBudget: default 968 MiB becomes 1000 MiB within existing 1024 MiB. This is conservative logical buffer/queue accounting, not RSS; decoding, owned normalized objects and unbounded memory-backend retention add costs. No new settings or budget weakening.

## Outcomes and observability

204 empty response acknowledges asynchronous admission, not durable storage. SPI classifications map to400/413/429/503/504/501/500 as appropriate. 429/503 have bounded 1–60 second Retry-After. Semantically rejected records or pipeline partial rejection return 400 fixed message stating accepted records may persist. Never return retryable 429 after committed acceptance; unexpected error with Accepted>0 or InternalFailures>0 maps 500 and may duplicate on retry. Do not swallow errors with zero outputs. Warn on transformations/rejections through a fixed ten-message-per-rolling-minute logger as other receivers; full selftelemetry population remains outside this slice.

## Acceptance

Focused red→green tests for JSON/gzip, headers/auth/tenant, schema/depth/count/duplicate/null/UTF8/metadata limits, true uncompressed-byte charge, statuses/partial/committed outcomes, cancellation/Stop/body-closejoin, realpipeline isolation; parserfuzz and race/goleak. Runtime health/routing/shutdown and exactbudget boundary tests. Integration launches checksum-verified pinned Vector 0.45.0 with Loki sink compression none/gzip (snappy implies protobuf and is outside scope), bounded local stdin fixture, bearer and tenant; inspect memory SPI for expected body/resource/metadata and other tenant empty. External test fails clearly without binary. Preserve Prometheus/OTLP external acceptance and security/daemon smoke. Full make lint test, guards+5negative, build, pinnedlint normal/integration, modulegraph identity, independent frozen-diff review and PR/mainCI before final acceptance.
