# P1-08: bounded Prometheus HTTP query API

## Goal and scope

Expose GET/POST query, query_range and series; GET labels, label/{name}/values, metadata and status/buildinfo under /prom/api/v1, through existing SPI and pinned Prometheus engine. Wire query and all-in-one runtime modes; ingest remains ingestion only. P1-07 is complete. Keep Go 1.27.1, module versions, public SPI/UTM identifiers and driver implementation unchanged. Rules/alerts/remote_read/runtimeinfo, ClickHouse, multi-tenant identity control plane, releases and deployment are later milestones.

## Identity and shared interface

This milestone preserves the existing single-tenant runtime boundary. The handler binds tenancy.default_tenant at construction; nonempty tenant headers may only equal it, never select another tenant. Reject ambiguous duplicate authorization/tenant headers. If allow_anonymous_read is false require constant-time verification of the existing ingest_api_key; if true requests without Authorization are allowed, while supplied invalid credentials still fail. Never expose keys, raw backend error text, expressions or header values in logs/errors. This narrows SDD 02 generic identity precedence until the control plane exists; ADR-016 records the deviation. Strict tenancy fails closed at startup in query/all-in-one as in current ingest, not silently treated as single.

Shared worker API (freeze before parallel implementation): promapi.NewQueryHandler(backend spi.Backend, options QueryOptions) (*QueryHandler,error); QueryHandler.HTTPHandler() http.Handler; Stop() cancels/refuses new requests; Close(ctx context.Context) error waits active handlers to exit. QueryOptions fields Tenant string, APIKey secret.String, AllowAnonymousRead bool, Config config.QueryConfig, Telemetry *telemetry.Registry, Logger *slog.Logger, Clock spi.Clock. Nil clock/logger choose system defaults; telemetry optional in tests. Handler borrows backend; runtime closes backend after handlers exit. QueryConfig existing settings remain canonical, no new config fields.

## HTTP and results

Use SDD 02 §2 native envelopes and `X-Prism-Error-Class` for all errors including method/auth/resource cases. `bad_data` 400, timeout/canceled/unavailable 503, `execution` 422, `internal` 500, `not_found` 404; auth 401/403 with a native envelope. `Retry-After: 1` for busy/stopped. Parse bounded URL/form requests with a 1 MiB total input cap, 64 KiB expression cap, at most 128 `match[]` selectors and scalar duplicate rejection; validate numeric finiteness/range before UTM conversion, RFC3339 allowed. Duration syntax accepts Prometheus units or finite positive seconds; range requires start/end/step, timeout cannot broaden configured deadline. Integer limit nonnegative, zero means server default; reject unknown/unsupported material options rather than silently weakening checks. Unknown routes and methods have deterministic native errors. JSON uses Go 1.27 `encoding/json/v2` with explicit v1 wire-compatible shapes and string samples; timestamps through UTM. Preserve vector/matrix/scalar/string and NaN/Inf spellings; empty arrays/objects never null. Buildinfo advertises compatible Prometheus 2.53.0 and prism revision/runtime Go per existing ADR.

The literal limit is a requested result truncation with warnings for instant queries and catalog endpoints; query_range follows the pinned endpoint parameter table and rejects limit with 400. Hard resource caps produce errors, never silent truncation. Enforce maximum 100,000 result series/label values/metadata records, at most 128 labels per series, 1 MiB cumulative label bytes per item, 64 MiB owned logical result metadata and 32 MiB encoded response, bounded warnings count/bytes, finite engine MaxSamples and adapter MaxRows. Preflight sizes before allocation/JSON encoding, keep response within cap before sending success. Backend allocation and engine internal MaxSamples memory are explicitly not process RSS bounds. No unbounded warning/error strings in outputs.

## Semantics, routing and safety

Parse AST before native/fallback dispatch: reject every reserved selector matcher except __name__, reserved grouping/vector matching/include labels and label_replace/label_join source and destination names, and count_values destination names; ensure final stored/system labels are never exposed (output validation/filtering defensive for native results). Validate syntax depth/node/work under input bounds, regexp and range/subquery/offset reach, not just outer HTTP times; reject attempts to bypass retention/window limits via @, offset, subqueries or selector ranges. Do not silently clamp inner AST semantics. Public labels APIs include __name__ when matching visible series exist, resolving P1-07's SPI LabelNames gap via bounded metric-name probing; no SPI/driver change. match[] selectors union and deduplicate; empty-matching selectors rejected as upstream; labels/values may omit match[]. Metadata uses optional MetadataStore with tenant and cap, absent support returns {}.

Native dispatch requires both declared NativePromQL capability and optional NativeMetricQuerier on backend.Metrics(); force_fallback always wins. SPI PromResult has no string payload, so parsed string expressions select engine fallback before dispatch with partial_pushdown reason. Native errors never trigger a second fallback execution. Test native/fallback with SPI fakes, real memory engine for fallback. Use Tier 1 for catalog APIs with finite cumulative work/metadata and Close all sets. No concrete driver assertions/imports in compat.

Apply configured timeout, lookback, max_range, max_points and fallback range/rows; range point arithmetic must not overflow and include endpoint. Old outer query start clamps to now-max_lookback+lookback_delta (five minutes inside the default evaluation boundary) with explicit warning/adjustment counter, so the engine’s implicit lookback does not read older than the configured storage floor. Catalog starts clamp directly to that floor; reject all-outside/inverted windows. Fixed tenant means no unbounded tenant state map. Admit with finite global and per-tenant limits before decode; release only after encoding/writing is complete. Stop cancels active operations before waiting; Close joins cancellation callbacks, no request/engine/storage access after return. Slow response clients need bounded write deadline and cancellation. All sets/query objects close on success/error/cancel. No goroutine per rejected request.

## Observability and runtime

Reuse existing registered query request/duration/fallback/concurrent/rejected and storage-query-duration metrics with fixed domains. The registered prism_query_adjustments_total{action=clamp_time|truncate_results} increments whenever user-visible time/results change. Errors observable by bounded counters or sanitized bounded logs; no dynamic query/tenant labels. Runtime registers telemetry once when self_monitor enabled; no duplicate registration. query/all-in-one serve read endpoints sharing the opened backend; all-in-one keeps ingest HTTP/gRPC. Shutdown stops/cancels query work, awaits it and pipeline drain before backend.Close. Missing read key is invalid only when anonymous disabled; existing ingest key requirements remain unchanged.

## Acceptance

Focused red-green tests for wire shape, methods/form/time/duration/query parsing, reserved AST/output, tenant spoofing, metadata/labels including __name__, native/forced-fallback, size/work caps, deadlines/concurrency/Stop/Close and error/warning propagation. Independent design and exact-final-source audit with adversarial overlays. Acceptance uses real promtool 2.53.0 to query an ephemeral all-in-one daemon after ingestion, asserts value and error envelopes, clean SIGTERM; integration and security cover query-only/ingest separation. Run native race/goleak/vet/format, pinned lint normal/integration, build, dependency guards+negative fixtures, official memory corpus, security, modulegraph/scope/doclinks, PR/main CI and remote hashes. Preserve all failed/red attempts; no skipped required checks hidden.

Numeric timestamp parser correction is documented in ADR-017: ParsePromTime rejects nonfinite/out-of-range seconds and rounds signed milliseconds symmetrically; public identifiers and the legacy direct SecFloatToMilli contract remain unchanged.

The numeric parser intentionally follows ADR-017 signed half-away-from-zero ties; upstream 2.53 Modf rounding can differ by 1 ms at floating ties (for example -1.2345). This is explicitly not bit-for-bit timestamp-tie equivalence.

Shutdown first cancels queries, closes HTTP connections when the graceful deadline expires, and then waits for active handlers before closing the borrowed backend. Context-compliant backends and blocked network writers are covered by runtime tests. A backend that ignores cancellation can delay this final wait indefinitely; the configured graceful deadline is not a hard process-exit guarantee.

Backend and engine warning text is untrusted diagnostic material. Preserve the presence of warnings with bounded fixed messages rather than echoing expressions, credentials or raw storage text. Resource-limit checks still fail explicitly instead of turning a too-large result into success.

PromQL expression-construction/type errors return 400/bad_data. Non-storage engine evaluation errors return 422/execution with `X-Prism-Error-Class: bad_request`; this HTTP distinction uses an internal wrapper and does not extend SPI error classes. Storage errors retain their SPI classification, and sample-cap failures retain too_large.

Catalog series scans and the bounded metric-name existence probe preserve backend warnings before closing the SeriesSet. Series scans accept at most 32 warnings, 4096 bytes each and 16384 bytes total per returned warning set. The metric-name probe enforces those count and total-byte caps cumulatively across selectors; excess fails with too_large. Accepted raw backend warning text becomes one fixed sanitized catalog warning, shared across selectors, while iterator and Close errors retain their classifications.
