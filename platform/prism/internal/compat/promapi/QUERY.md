# Prometheus read API (P1-08)

`NewQueryHandler` borrows an `spi.Backend` and binds one configured tenant. `HTTPHandler` serves `/prom/api/v1/query`, `/query_range`, `/series`, `/labels`, `/label/{name}/values`, `/metadata`, and `/status/buildinfo`. `Stop` refuses admission and cancels active requests; `Close(ctx)` waits for all admitted handlers, including response writes, and does not close the backend.

The handler accepts GET query parameters and URL-encoded POST forms on query, query_range, and series. Input is capped at 1 MiB, expressions at 64 KiB, and `match[]` count at 128. Singular duplicate and unsupported parameters fail. Every API error has a Prometheus v1 envelope and `X-Prism-Error-Class`. Authentication binds the configured tenant; Authorization is a bearer key unless anonymous read is enabled. A supplied invalid key still fails. `X-Prism-Tenant` and `X-Scope-OrgID` can only confirm the bound tenant.

PromQL is parsed and validated before routing. Reserved system labels cannot be matched, grouped, used for vector matching, or sourced/destined by label functions. Selector time reach includes offsets, ranges, subqueries, and `@` modifiers. Old outer range starts are clamped to the first evaluation time whose implicit lookback remains within `max_lookback`; an explicit warning and adjustment counter record the change. Native execution requires both the declared capability and optional `spi.NativeMetricQuerier`; force_fallback and string results use the pinned Prometheus engine with the tenant-scoped SPI adapter. A native error is never retried through fallback.

Catalog paths use Tier-1 operations with finite cumulative work and close every series set. The public label list probes for `__name__`, since some stores omit it from `LabelNames`; probe warnings are bounded across selectors and emitted once as a sanitized catalog warning. Stored system labels are removed from result metrics. Hard caps reject excess series, labels, metadata, samples, warnings, and responses; the requested `limit` truncates eligible results with a warning and adjustment metric. JSON uses Go `encoding/json/v2`, and successful responses are encoded only after a conservative escaping preflight. Backend allocations and the engine's `MaxSamples` do not constitute a process RSS limit.

The HTTP handler does not own the listener. Its request context has the configured deadline, and POST reads and response writes have deadlines. Runtime shutdown should call `Stop`, then `Close(ctx)`, then close the borrowed backend.
