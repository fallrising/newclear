## Summary

Implemented durable M4 delivery storage in the assigned SQLite/store scope. Migration 004 preserves earlier event, source, rule and audit data. Runtime activation commits safe subscription definitions with sources/rules; identities are immutable while endpoint and credential-reference rotations remain outside persisted definitions. Removing a subscription pauses scanning/attempts and re-adding resumes. Replay of an inactive subscription is rejected.

Immediate projection preserves event bytes and commits a bounded batch with its scan cursor. Digest projection freezes event-time windows, post-activation sequence bounds, the matching total and first 20 events; empty windows persist their advancement, completed windows ignore later arrivals, and initially empty `earliest_hot` subscriptions wait for the first event before choosing their boundary. Each tick processes at most 200 immediate events or 31 digest windows per active subscription.

Claims persist an attempt and a two-minute opaque lease before network I/O. Expired claims are recovered with a sanitized interruption record; stale completion tokens cannot overwrite newer attempts. HTTP status drives retry classification even when the sender provides an error summary. Twelve attempts exhaust each replay cycle while lifetime counters remain cumulative. DLQ transition/event and replay/audit updates are transactional. Queries use the OpenAPI response fields, delivery ID ascending ordering, filter-bound strict cursors and bounded pages.
