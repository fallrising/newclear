One confirmed P2 finding was corrected and independently reverified; no unresolved implementation blocker remains:

**R1 — CLOSED: Preserve the full accepted event-time domain when persisting and exposing digest boundaries.** `internal/store/subscriptions.go:134` serializes the earliest digest boundary as UTC RFC3339, then `internal/store/deliveries.go:146` reparses it. With an initially empty `earliest_hot` daily UTC digest plus an immediate subscription, ingest the valid event time `9999-12-31T23:59:59-23:00`. The derived boundary is `10000-01-01T00:00:00Z`, which Go's RFC3339 parser rejects. `QueueDeliveries` rolls back the whole projection transaction and the dispatcher returns before attempting any queued work; an accepted future event can therefore block unrelated immediate delivery. The failure repeats until data/configuration changes. Use a durable boundary representation that round-trips all accepted event instants, while retaining the stable ID and actual schedule.

The same conversion at `internal/store/deliveries.go:201` and `internal/delivery/message.go` produces a public `window_start` and board link outside the date-time contract at the lower boundary. Accepted input `0001-01-01T00:00:00+23:00` produces `window_start: 0000-12-31T00:00:00Z`; this fails the same event-time validation used for board query bounds. A finite-domain clipping policy for otherwise unrepresentable outer boundaries, plus valid-offset serialization near the bounds, preserves all valid events without weakening the schema. The final correction stores `digest_start` as signed Unix seconds and reconstructs it with `time.Unix`; public bounds use the documented finite-domain clipping and valid-offset formatting. The stable ID and internal half-open schedule remain exact. All four original independent overlay probes now pass under the race detector, including both original failures. The native suite adds both regressions and valid digest-link bounds. This closes R1.

No confirmed SSRF, credential disclosure, normal-clock retry/DLQ/replay, cursor, lease-fencing or UI cancellation defect was found.
