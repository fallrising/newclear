## Summary

Implemented `HTB-P0A-001` as a deterministic pure-Go kernel under the new Go 1.27 module. The
domain package provides typed identities and SHA-256 digests, immutable canonical completion
subjects and evidence/review/approval records, orthogonal WorkItem conditions and blockers,
versioned guarded transitions, retry identity and idempotency decisions, stable rejection codes,
and an atomic value result that makes `CompleteWorkItem` the only path into Done.

The reconciliation package provides deterministic typed-DAG validation and diagnostics, normative
stable-ID graph differencing, old-plus-new reverse closure with all shortest cause paths and a hard
capacity rejection, identity-bound ImpactPlans, stale activation checks, and complete/unknown reuse
fingerprints. Tests use hard-coded expected state, paths, canonical JSON and independent SHA-256
calculation rather than calling production transition/closure logic as an oracle. They cover the
T-020 core of AC-23 through AC-31, including removed edges, stable-ID path renames, unmapped required
nodes, stale run/policy/read sets, stale publication, historical Done-Stale and changed recipe or
environment dimensions.
