## Summary

Implemented the bounded HAI-CI-001 root workflow with separate digest-pinned backend and web jobs.
Both PR and main-push path filters cover the component and workflow; manual dispatch, read-only
contents permissions, cancellation concurrency, job timeouts and immutable credential-free
checkout are explicit.

Added common local/CI backend and web gate scripts plus a shell-only pin comparison gate. The
backend fails on the wrong Go runtime or missing race compiler before downloading modules, then
downloads/verifies modules and runs format, vet, full tests, race and build. The web fails on
incorrect Node/pnpm versions before frozen installation with lifecycle scripts disabled, then runs
the existing format, lint, unit and build scripts; build includes TypeScript checking. CI checks
Node before bootstrapping the exact pnpm version without generating a lockfile.

The pin gate compares the workflow image digests against reproducibility documentation, checks
the Go language/toolchain declarations, Node version file, package-manager and engine pins, and
checks CI's pnpm bootstrap version. Runtime-specific modes work in their respective images
without requiring Python or adding another runtime.
