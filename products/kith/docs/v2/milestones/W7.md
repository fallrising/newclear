## 0. 開發規則（使用者指定，照抄，全程有效）

- 不在寫完程式後補單元測試。
- E2E 是主要且預設唯一的測試手段；每次 E2E 產出證據資料夾（[08](../08-testing-e2e.md) §4）。
- 必須單獨測試某個系統時，先寫出所有失敗方式（FM 清單），再寫程式。
- 開發期間不跑全套 E2E，只跑當前里程碑的 spec。
- 文件先行：實作中發現本檔錯誤，停下，先改本檔（同 PR 內獨立 commit，說明原因），再繼續。

W7 沒有新的「必須單獨測試的系統」。切換本身的失敗方式列在 §8（FM-CUT-01–08），寫程式前先讀。本里程碑的驗收本身就是全套 E2E（`E2E-W7-01`，[09](../09-roadmap.md) W7）；開發期間仍只跑 `@W7` 與被修改的 spec，全套只在 W7-T10 跑。

### 5.3 `E2E-W7-02` 的量測工具（寫在 spec 檔內，不另立 harness 模組）

```ts
import { readFileSync } from "node:fs";
import { join } from "node:path";
import { gzipSync } from "node:zlib";
import type { Page } from "@playwright/test";
import { WEB_DIST_DIR } from "../harness/paths.ts";

const BUDGET_BYTES = 250 * 1024; // Q-31
const CONSOLE_MARKER = "console-nav-agents"; // W4 §5.4 的 data-testid，只存在於控制台 chunk

/** Same-origin /assets/*.js paths the page requests, in order of first response. */
function collectJs(page: Page, origin: string): string[] {
  const seen: string[] = [];
  page.on("response", (r) => {
    const u = new URL(r.url());
    if (u.origin === origin && u.pathname.startsWith("/assets/") && u.pathname.endsWith(".js") && !seen.includes(u.pathname)) {
      seen.push(u.pathname);
    }
  });
  return seen;
}

function distFile(pathname: string): Buffer {
  return readFileSync(join(WEB_DIST_DIR, pathname.slice(1)));
}

/** zlib default level; equals the "gzip:" column vite prints (§10). */
function gzipBytes(pathname: string): number {
  return gzipSync(distFile(pathname)).length;
}

function p95(samples: number[]): number {
  const s = [...samples].sort((a, b) => a - b);
  return s[Math.ceil(0.95 * s.length) - 1]!;
}
```

### 5.4 條件式：`markdown-it` 延後載入（只有 §7.2 步驟 2 的總量 > 250 KiB 才做）

實測（§10）：把 `markdown-it` 改為動態 import，首頁 chunk 少 41.6 kB（gzip）。做法：訊息先以純文字顯示，`markdown-it` 載入後（啟動時就開始載）重新渲染成 Markdown。

`web/src/markdown/md.ts`（取代 W1 §5.4 的內容；規則清單與 `validateLink` 一字不改，搬進 `loadMd`）：

```ts
import type MarkdownItCtor from "markdown-it";

type MarkdownIt = InstanceType<typeof MarkdownItCtor>;

let instance: MarkdownIt | null = null;
let pending: Promise<MarkdownIt> | null = null;
const listeners = new Set<() => void>();

/** Starts loading markdown-it once; resolves to the configured instance (W1 §5.4 rules). */
export function loadMd(): Promise<MarkdownIt> {
  pending ??= import("markdown-it").then(({ default: MarkdownItClass }) => {
    const md = new MarkdownItClass("zero", { html: false, linkify: true, breaks: true });
    md.enable(["fence", "blockquote", "list", "paragraph"]);
    md.enable(["text", "linkify", "newline", "escape", "backticks", "emphasis", "link", "autolink"]);
    md.enable(["balance_pairs", "fragments_join"]);
    md.enable(["normalize", "block", "inline", "linkify", "text_join"]);
    md.validateLink = (url: string): boolean => /^(https?:|mailto:)/i.test(url.trim());
    instance = md;
    for (const listener of listeners) listener();
    return md;
  });
  return pending;
}

export function subscribeMd(listener: () => void): () => void {
  listeners.add(listener);
  return () => {
    listeners.delete(listener);
  };
}

export function getMd(): MarkdownIt | null {
  return instance;
}
```
