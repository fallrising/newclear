# Memvid

第三方參考：[memvid/memvid](https://github.com/memvid/memvid)，Apache-2.0。
閱讀基準為 [`e6bd9f7b9c38cd8d5370fa0fc936ac1dcd751813`](https://github.com/memvid/memvid/tree/e6bd9f7b9c38cd8d5370fa0fc936ac1dcd751813)。

Memvid v2 將內容、索引與 metadata 放在 `.mv2` 記憶檔，提供檢索、時間線與可選模型能力。
本目錄只保存參考入口；上游 source 不匯入 monorepo。

使用它的第一方實驗在 [labs/memvid-lab](../../labs/memvid-lab/README.md)：11 類官方記憶場景、PDF、本地文字模型、CLIP 與 native Whisper，採固定套件、模型雜湊及內容驗收。
文件與實際套件的差異見 [上游閱讀紀錄](../../labs/memvid-lab/docs/upstream.md)，完成程度以 [SUCCESS](../../labs/memvid-lab/SUCCESS.md) 為準。
