## VPS 測試授權

需要 VPS 測試時，可自行從 `~/.ssh/config` 查找候選主機，檢查連線、CPU／記憶體／磁碟、現有程序／容器／服務及測試任務，選擇空閒且適合本項目的機器。不要只憑低負載判定空閒，也不要把整份 SSH 設定或憑證貼進報告。

Owner 已授權：必要時可以停掉機器上的測試服務（例如 ERU），騰出本項目測試資源，不需要為這類已授權停測再次詢問。操作前確認精確服務、用途及目前是否承載其他執行中的測試；記錄原狀態、停止／恢復方式並保留資料與設定。優先正常停止；涉及其他正在使用的任務先協調，不能確認用途就換機或釐清。測試後釋放本次資源並依記錄恢復原測試服務，驗證恢復結果；若無法恢復，保留明確接手資訊。

此授權涵蓋必要的隔離測試啟停，不等於刪除 ERU／測試資料、全域 prune、重灌主機、停正式服務、購買資源或正式部署。公開文件只記去識別證據，真實主機名、IP、帳號、私有設定及憑證留在 repo 外。需要 macOS、圖形介面、真人登入或特定外部系統的 AC，不能以 VPS mock 測試代替。
