## 來源摘要

以下是對公開條目的短篇改寫，只保留機制本身，不含案例、圖片或原站程式。

來源把「Item-filtered transport」定義成：為混合物流設定規則，讓不同物品自動走向正確出口。可對上的規則片段是：正確分類、誤投與溢位構成反饋。

來源循環的順序是：檢視混入的物品 → 配置過濾條件 → 設定未匹配出口 → 測試異常輸入。

來源要玩家自行權衡的兩件事，以下僅作繁體轉寫，不是本筆記的結論：「精細白名單更可靠，但新增產品時需要維護。」「保留回收通道佔空間，卻避免一個異物停掉全線。」

## 問題與情境（本地分析）

以下各節由模型依本筆記的來源摘要起草，屬本地設計分析，尚未經人工審閱，也不代表來源作者的觀點。

在生產線同時跑出多種物料時，若全靠手動分揀，產能會被搬運與看管吃掉，也很難把錯誤轉成可讀的訊號。物品篩選把「哪種東西該去哪裡」抽成規則，讓玩家用過濾條件描述意圖，系統則以誤投、溢位與回收通道的狀態回報規則是否貼合實際物流。

它適合已經有多條下游產線、且物料會混流的自動化場景，特別是玩家願意為了長期穩定而維護規則表的時候。若產物種類極少、或錯誤代價遠低於維護成本，改成單純的單一路徑或手動插入反而更清楚；在完全沒有可觀察回饋的情況下，硬塞規則只會讓問題更難診斷。

## 核心循環（本地分析）

- 玩家行動：玩家先觀察管線裡混進了哪些物品，替每一類設定允許通過的條件，再指定不符合任何條件的物品該被送往哪裡，最後故意投入幾種異常物料來驗證。
- 系統回饋：系統會顯示哪些物品被導向哪個出口、是否有物品誤入不該去的分支，以及未匹配出口或回收通道是否開始堆積。
- 下一個決策：看到誤投或溢位後，玩家會回頭收緊或放寬條件、補上新的白名單項目，或調整回收通道的容量與位置，再跑一次異常輸入。

## 解法與取捨（本地分析）

- 白名單寫得越精細，分流越可靠，但每當產線新增一種產品，就得回來補規則，維護負擔會隨品項數量成長。
- 保留專用的回收或溢位通道能吸收異物、避免整條線被單一雜物堵死，代價是永久佔用空間與一部分輸送容量。
- 把未匹配出口設得過寬，異物容易混進主線；設得過窄，正常但尚未登記的物品也會被擋下，兩端都會製造額外的人工追查。

## 可調參數（本地分析）

- 「物品種類」：品項少時，玩家可以用很細的條件逐項指定，規則表容易讀懂；品項一多，條件數量與交互作用快速膨脹，玩家傾向改用較粗的分類或依賴回收通道，分流精度與維護成本於是此消彼長。
- 「錯誤後果」：後果輕時，玩家敢放寬條件、容許少量誤投，把重心放在吞吐；後果重時，玩家會加嚴白名單並擴充溢位與回收設計，測試異常輸入的次數也明顯增加。

## 失敗模式（本地分析）

- 規則表長期沒有更新，新增物品一律落進未匹配出口，回收通道被塞滿後反而成為全線停擺的瓶頸。
- 過度依賴單一未匹配出口，把所有不確定物品都往那裡丟，玩家難以從回饋分辨究竟是條件寫錯還是物品本身少見。
- 品項數量龐大且變動頻繁時，逐項維護條件的成本超過分流帶來的收益，此時規則系統只是把混亂從輸送帶搬到設定介面。

## 最小原型與驗收（本地提案）

此原型尚未實玩驗證。下列通過與否是本地判斷。

- 最小範圍：（本地分析）做一個小場景，讓玩家依序經歷「檢視混入的物品」、「配置過濾條件」、「設定未匹配出口」、「測試異常輸入」。來源的原型第一步是「只用三類物品、一個過濾節點和默認出口，顯示每種物品最終走到哪裡」。
- 驗收：（本地分析）對照來源規則「玩家設定允許通過的物品類型，把混合輸入拆成專線」。通過要能滿足「故意混入一種新物品，觀察玩家是否能給它安排去處並保持原線路運行」，並分得出「精細白名單更可靠，但新增產品時需要維護」。做不到就算失敗。
- 邊界驗收：（本地分析）來源指出要避開的情況是「規則優先級與“沒有匹配”必須可見，避免玩家只能靠反覆拆線調試」。通過要直接檢查這件事：踩進這個情況時，結果必須和避開時不同；看不出差別，就不算測到這個邊界。

## 相關模式

- [空中搬運物流](automation-aerial-logistics.md)：（本地分析）兩者都處理多來源、多目的地的搬運排程，但空中物流靠覆蓋與能源規劃吞吐，物品篩選則在既有路徑上用條件決定去向。
- [受限空間中的物流路由](automation-belt-routing.md)：（本地分析）輸送路由決定路徑與容量，物品篩選在其上疊一層分類規則；前者讓排隊在空間中可見，後者讓錯誤分類變成可讀訊號。
- [藍圖重用](automation-blueprint-reuse.md)：（本地分析）藍圖重用把驗證過的生產單元複製到新場地，物品篩選的規則表同樣需要可移植與再適配，否則每次複製都得重寫條件。
- [副產品循環](automation-byproduct-loop.md)：（本地分析）副產品循環處理不想要的產出，物品篩選則決定哪些東西該進入那條循環；兩者常搭配，但前者關注去處，後者關注判定條件。
