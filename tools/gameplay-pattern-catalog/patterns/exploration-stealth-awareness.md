## 來源摘要

以下是對公開條目的短篇改寫，只保留機制本身，不含案例、圖片或原站程式。

來源把「Escalating awareness and stealth routing」定義成：被看見並非立刻失敗，警覺階段為玩家留下處理視窗。可對上的規則片段是：在敵人的視線、聽覺和巡邏路線間移動。可疑行為會先累積警覺，再升級為搜索或戰鬥；玩家可以停下、遮擋視線、製造誘餌或換路，而警覺回饋幫助玩家理解哪裡出了問題。

來源循環的順序是：觀察巡邏與視線 → 選擇遮擋與時機 → 通過或製造誘餌 → 處理警覺後繼續。

來源要玩家自行權衡的兩件事，以下僅作繁體轉寫，不是本筆記的結論：「等待巡邏離開最穩，製造聲音更快，卻會改變後續巡邏狀態。」「發現屍體或違法動作會帶來連鎖後果，路線必須考慮離開時的狀態。」

## 問題與情境（本地分析）

以下各節由模型依本筆記的來源摘要起草，屬本地設計分析，尚未經人工審閱，也不代表來源作者的觀點。

潛行玩法若把「被看見」直接判成失敗，玩家就只剩背路線一條路。這個機制把視線、聽覺與巡邏當成可讀的資訊資源，讓被注視變成一段可以介入的過程，玩家能靠遮擋、時機或誘餌把局面拉回來。

適合有固定巡邏守衛、多條可行路線、以及可製造聲響之物的關卡，例如倉庫、宅邸或軍營。若場景只有一條窄道、守衛不會移動，或玩家無法從畫面上讀出警覺程度，這個機制就只剩計時壓力，玩家也沒有等、繞、引這三種手段可以比較。

## 核心循環（本地分析）

- 玩家行動：玩家貼著掩體觀察守衛的視線方向與聽覺範圍，判斷巡邏的空檔，再決定停下等待、繞過遮擋，或丟出聲響把守衛引往別處。
- 系統回饋：守衛的視線指示、逐格填高的警覺計量、轉頭與搜索的動作，以及最後是回到巡邏、進入搜索還是轉為戰鬥，都會即時顯示在畫面上。
- 下一個決策：警覺高低與守衛停留的位置，決定下一段能不能照原路走；若守衛被引開、進入搜索或轉入戰鬥，玩家就得改走別的出口，或先處理被留下的屍體與痕跡。

## 解法與取捨（本地分析）

- 等待巡邏離開最穩，但吃掉時機窗口，也可能讓後續守衛的位置變得難預測；製造聲音能開出捷徑，代價是守衛之後的站位與警覺值被改寫，回程反而更難走。
- 屍體或被目擊的違法動作會連鎖放大警戒，因此路線規劃不能只想怎麼進去，還要預留退出的掩體與可以收拾痕跡的物件。
- 警覺累積速度與搜索持續時間共同決定容錯空間：兩者都放寬會讓玩家直接衝過去，收得太緊則一次擦邊就等於整段重來。

## 可調參數（本地分析）

- 「警覺累積速度」：往下調，玩家能連續擦過視線邊緣，試錯成本低，容易變成一邊小跑一邊觀察；往上調，被瞄到一下就迫使玩家立刻中斷動作或躲藏，節奏偏向停等與反覆確認。
- 「搜尋持續時間」：拉長會讓玩家傾向躲在掩體裡等守衛放棄，路線規劃變成等待管理；縮短則躲藏價值下降，玩家更願意賭時機硬闖，或改用誘餌把守衛調離原本的位置。

## 失敗模式（本地分析）

- 警覺只有「沒事」與「失敗」兩種反應，玩家看不到累積過程，無法判斷還能冒險多久，這個機制就只剩下躲避視線的小遊戲。
- 場景缺少替代路線，掩體之間的間隔又太短，玩家沒有等待、繞路、引開這三種做法可比較，只能在唯一的窄道上賭運氣。
- 守衛搜索結束後回到原位、警覺也完全歸零，前面製造的聲響與留下的痕跡都不影響後續，玩家自然會選擇最快但最吵的做法。

## 最小原型與驗收（本地提案）

此原型尚未實玩驗證；範圍與數字都是本地測試設定，不是來源遊戲參數。

- 最小範圍：一張小房間圖：兩名巡邏守衛、三處掩體、一顆可投擲的誘餌；警覺分 0 到 3 階，滿 3 階進入為期 8 秒的搜索，用來觀察玩家是否願意用誘餌換時間。
- 驗收：Given 守衛 A 沿直線來回巡邏，視野 90 度、距離 4 格；玩家從入口走到目標物必須穿過其視野，路徑中段有一處掩體。 When 玩家趁守衛背對時前進兩格，然後在掩體後停下等待，不做任何聲響。 Then 警覺維持在 0，守衛依原路線離開，玩家可在其轉身後繼續前進；紀錄等待時間與通過所需時間，確認保守做法不會觸發搜索。
- 邊界驗收：Given 同一張圖，警覺起始為 0 階；玩家在守衛正面 3 格處投出誘餌，誘餌落在側邊 2 格的位置。 When 守衛轉向誘餌並停留 3 秒，警覺每秒累積 1 階，3 秒後由 0 階累積到 3 階、剛好達到滿階門檻；玩家趁這段空檔穿過原本被看守的路線。 Then 警覺停在 3 階並觸發為期 8 秒的搜索，守衛離開原本路線改為搜索；8 秒搜索結束後，警覺歸零，守衛改為在誘餌落地處附近巡邏；玩家回程必須另找掩體或再等一輪，驗證「更快但改寫後續巡邏狀態」確實發生。

## 相關模式

- [光影之間的路線](stealth-light-shadow.md)：兩者都在切分空間的可通行程度：光影決定哪裡能停留、哪裡得快速通過，警覺則決定衝過去之後守衛會不會追上來。
- [聲音誘餌](stealth-sound-lures.md)：誘餌是警覺系統的主要輸入之一，製造聲響同時開出捷徑並改寫守衛站位，等於用同一個資源換取時間與風險。
- [藏點與脫離時機](stealth-hiding-spots.md)：躲藏點提供暫停警覺累積的手段，但出來的時機取決於搜索還剩多少時間，兩者都要判斷「何時現身」。
- [同步動作](stealth-synchronized-actions.md)：同步動作先把多名守衛的視線與巡邏錯開，警覺機制則負責處理錯開失敗後逐級升高的連鎖後果。
