## 來源摘要

以下是對公開條目的短篇改寫，只保留機制本身，不含案例、圖片或原站程式。

來源把「Repeat a time window with a different event plan」定義成：世界回到起點，玩家用上一輪的發現改變下一輪安排。可對上的規則片段是：重點是重新安排整段事件，不是逐幀撤銷剛才的動作。

來源循環的順序是：觀察這一輪的事件順序 → 記住障礙與時間條件 → 重置後改變行動安排 → 驗證變化並獲得下一條線索。

來源要玩家自行權衡的兩件事，以下僅作繁體轉寫，不是本筆記的結論：「本輪繼續追一個新發現，還是先驗證已經想到的解法？」「提早改變一個事件，是否會錯過原本想觀察的後續？」

## 問題與情境（本地分析）

以下各節由模型依本筆記的來源摘要起草，屬本地設計分析，尚未經人工審閱，也不代表來源作者的觀點。

當一輪能看完的資訊量有限，玩家往往只會沿著固定路線撿東西；這個機制把時間窗當成可重排的排程單位，讓上一輪記下的障礙與時序條件成為下一輪的安排依據。推理、調查或日常循環類的情境都適用：玩家先觀察事件先後，再決定把哪個行動挪前、哪個留到後面。

事件彼此獨立、順序不影響結果的場合並不適合，因為重排不會生出新資訊；時間窗拉得太長也不適合，玩家記不住上一輪的因果，重排就變成亂試。若世界重置後帶不走任何觀察，這個機制同樣失去意義。

## 核心循環（本地分析）

- 玩家行動：在時間窗內依序跑事件，記下哪個障礙卡在什麼時點，重置後把行動重排成另一份順序，例如把原本排在後段的對話挪到開頭。
- 系統回饋：系統重播這一輪的事件序列，讓玩家看到被挪動的事件如何改變後續觸發；新線索、被跳過的段落、沒發生的對話都直接標在時序上。
- 下一個決策：玩家從回饋判斷哪個改動值得保留、下一輪要先追新發現還是先驗證已想到的解法，並決定是否再往前挪一格。

## 解法與取捨（本地分析）

- 重排幅度越大，能觀察到的變化越多，但原本想看的後續也越容易被擠掉；設計上要讓玩家清楚自己犧牲了哪段觀察。
- 跨迴圈保留的內容越多，玩家越能規劃，但每輪的驚喜與重新解讀的空間被壓縮，熟悉感與新鮮感需要抓平衡。
- 迴圈長度縮短能加快驗證節奏，卻讓時序條件變得扁平，障礙與時間之間的因果不易被讀出來。

## 可調參數（本地分析）

- 「迴圈長度」：縮短會讓每輪只夠驗證一個改動，玩家傾向小步試錯；拉長則讓一次重排牽動更多事件，玩家得更早決定放棄哪段觀察，負擔與滿足感一起上升。
- 「跨迴圈保留的內容」：只保留筆記式線索時，玩家每輪都要重新推理；保留越多狀態（如已解鎖的對話、已知障礙），重排就越像在已知地圖上做最佳化，探索感下降。

## 失敗模式（本地分析）

- 重置後只回放結果、不顯示事件順序的變化，玩家無從得知是哪個改動造成差異，重排變成盲猜。
- 若每個事件都能獨立重排且互不影響，玩家會找到一組萬用順序，之後每輪照抄，機制就沒有張力。
- 時間窗太長又沒有中途標記，玩家記不住上一輪的障礙時點，只能靠運氣，學習曲線變成記憶力測驗。

## 最小原型與驗收（本地提案）

此原型尚未實玩驗證；範圍與數字都是本地測試設定，不是來源遊戲參數。

- 最小範圍：最小原型：一個 3 段時間窗、4 個可排事件、1 個會擋路的障礙，玩家能重排並重置 2 輪，系統只記錄事件順序與觸發結果。
- 驗收：Given 時間窗分為 A、B、C 三段，共 4 個可排事件 E1、E2、E3、E4；E1 需在 A 段，E2 需在 C 段，E3 無時段限制但排在 B 段會被障礙 X 擋下，E4 無時段限制，且每段可容納多個事件。 When 第一輪排成 A：E1、E4；B：E3；C：E2，結果 E1、E4、E2 觸發（3 個），E3 被 X 擋下（1 個）；重置後只把 E3 從 B 移到 A，其餘 E1、E4、E2 不動，新安排為 A：E1、E4、E3；B：空；C：E2。 Then 系統回報 E3 在 A 段成功觸發並解鎖線索 L1；E1、E4、E2 仍依原時段觸發，最終 4 個事件全部觸發、0 個被擋，沒有事件因順序變動而失效。
- 邊界驗收：Given 同上設定（3 段、4 個事件、1 個障礙 X，E1 需 A、E2 需 C，E3 排 B 會被 X 擋下），但把跨迴圈保留設為只留線索、不留已知障礙位置。 When 第二輪玩家不知道 X 在 B，誤把 E3 排到 B 段，其餘 E1、E4 排 A 段、E2 排 C 段。 Then 系統應顯示 E3 仍被 X 阻擋且不給出新線索；本輪最終 3 個事件觸發、1 個事件被擋，驗證保留內容不足時玩家無法累積有效規劃。

## 相關模式

- [證據反駁](narrative-evidence-rebuttal.md)：兩者都拿上一輪取得的資訊回頭改動安排，但證據反駁是用事實去頂一句具體陳述，循環事件時程改的是整段事件的順序，而非單點指認。
- [調查時間時段](narrative-investigation-time-slots.md)：兩者都在有限時間裡取捨；調查時間時段決定這一輪放棄哪條線索，循環事件時程則把同一條線索換到不同時點再試一次。
- [背景事件對話進出](narrative-background-dialogue-access.md)：背景事件對話進出靠身份與經歷換取不同回答，循環事件時程靠改變事件先後來打開原本關上的對話機會。
- [對話介入](narrative-conversation-intervention.md)：對話介入管的是開口的時機點，循環事件時程管的是整段事件的排列；前者是單一對話內的節奏，後者是跨事件的時序規劃。
