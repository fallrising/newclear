## 來源摘要

以下是對公開條目的短篇改寫，只保留機制本身，不含案例、圖片或原站程式。

來源把「Persistent currency between attempts」定義成：這一趟沒通關，也能為下一趟留下可用的提升。可對上的規則片段是：局內臨時收益要與永久資源清楚區分。

來源循環的順序是：進入一次挑戰 → 積累可保留資源 → 結束後購買長期提升 → 帶著新起點再試。

來源要玩家自行權衡的兩件事，以下僅作繁體轉寫，不是本筆記的結論：「這次爭取過關，還是走更容易拿成長資源的路線？」「買便宜的即時提升，還是攢錢等待能改變打法的大升級？」

## 問題與情境（本地分析）

「跨局保留的永久貨幣」要處理的情況是：玩家已經能做「進入一次挑戰」，但重複這個動作不會自動得到好結果。這類問題的關鍵是這一次的承諾會跨過單場戰鬥留下。這個條目同時壓在這些設計張力上：這次選擇會留下之後還能用的能力、存量會改寫下一步還能做什麼、收益與損失綁在同一個選擇上。

適合放進玩家下一步會被「結束後購買長期提升」改寫的系統。若結果在行動前就公布標準答案，這個設計問題會消失。不適用於每一場結束都完全清掉、沒有任何承諾留下的結構。

這裡的判斷是本地設計分析，不是來源作者的意圖，也不是案例遊戲的實驗結果。

## 核心循環（本地分析）

- 玩家行動：承諾「進入一次挑戰、積累可保留資源」。這一動是玩家主動付出去的部分，不能事後假裝沒有做過。
- 系統回饋：對該行動給出與「結束後購買長期提升」對應、而且能區分成功、部分成功與失敗的結果。只給一個總分不算回饋。
- 下一個決策：玩家依回饋決定要不要進入「帶著新起點再試」，或改走成本不同的另一條路。若回饋不能改變這個選擇，循環就沒有學習價值。

## 解法與取捨（本地分析）

- 在「積累可保留資源」就給出還能不能回頭的資訊，讓玩家不必等到「帶著新起點再試」才知道「這次爭取過關，還是走更容易拿成長資源的路線」這題選錯了。
- 「失敗時保留比例」用來回答第一個難點；「升級對起點的影響」用來回答「買便宜的即時提升，還是攢錢等待能改變打法的大升級」。兩個旋鈕如果綁在同一段回饋裡，玩家無法知道自己該改準備還是該改收尾。
- 「進入一次挑戰」保留一條較穩的走法，「帶著新起點再試」保留一條收益或資訊更高的走法。兩條路的結果必須長得不一樣，否則這個機制沒有選擇。

## 可調參數（本地分析）

- 本地預期：把「失敗時保留比例」調緊時，「進入一次挑戰」之後更難進入「積累可保留資源」；調鬆時，「積累可保留資源」變容易，前面的準備可能失去重量。先只動這個軸。這不是來源遊戲的實測參數。
- 本地預期：把「升級對起點的影響」調緊時，「帶著新起點再試」更常接不上「結束後購買長期提升」；調鬆時，「結束後購買長期提升」幾乎總能銜接，取捨會消失。先只動這個軸。這不是來源遊戲的實測參數。
- 不要把上述旋鈕寫成某一款遊戲的官方數值。來源若提到調整方向，也只是編輯分析，不是實驗報告。

## 失敗模式（本地分析）

- 若玩家看不出「進入一次挑戰」如何導致「結束後購買長期提升」，就只會記住成敗。以這個條目來說，規則片段「局內臨時收益要與永久資源清楚區分」一旦不可觀察，學習就停止。這是本地失敗判斷，不是來源記載的實玩統計。
- 張力是「這次選擇會留下之後還能用的能力」。若介面沒有把這個張力顯示成不同狀態，「帶著新起點再試」會退化成固定手順。
- 不適用於每一場結束都完全清掉、沒有任何承諾留下的結構。在那種結構裡硬加「帶著新起點再試」，只會多一個沒有決策的動畫。

## 最小原型與驗收（本地提案）

此原型尚未實玩驗證。範圍、數量與文字都是本地測試設定，不是來源遊戲參數，也不是原站原型文案。

- 最小範圍：只實作「進入一次挑戰」「結束後購買長期提升」「帶著新起點再試」三種可區分狀態，不搬原站插圖、案例關卡或程式。
- 驗收：Given 玩家已完成「進入一次挑戰」且系統處於可觀察的中間態，When 玩家選擇走向「結束後購買長期提升」，Then 回饋必須指出結果屬於哪一類，並給出一個與「帶著新起點再試」不同的下一步。
- 對照：Given 玩家停在中間態不操作，When 超過一個可辨識的等待，Then 結果必須與主動選擇不同，避免不操作也算過關。
