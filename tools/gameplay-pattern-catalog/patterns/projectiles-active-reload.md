## 來源摘要

以下是對公開條目的短篇改寫，只保留機制本身，不含案例、圖片或原站程式。

來源把「Press again inside the reload window」定義成：把等待裝填的時間，變成一次可以爭取額外收益的小判斷。可對上的規則片段是：裝填開始後，指標經過一個可見的成功區。玩家在窗口內再次按鍵，可縮短等待或強化下一輪射擊；錯過時按普通裝填完成，或承受事先說明的懲罰。

來源循環的順序是：選擇開始裝填的空當 → 跟隨進度條找視窗 → 再次按鍵爭取獎勵 → 利用新彈匣繼續行動。

來源要玩家自行權衡的兩件事，以下僅作繁體轉寫，不是本筆記的結論：「周圍安全時爭取強化，還是在被追趕時把注意力全留給走位？」「提前裝填以準備下一次交戰，是否會浪費剩餘彈藥或當前攻擊機會？」

## 問題與情境（本地分析）

以下各節由模型依本筆記的來源摘要起草，屬本地設計分析，尚未經人工審閱，也不代表來源作者的觀點。

換彈常是節奏裡最沒有互動的一段：玩家只能等，操作被抽空，這段空白既不產生判斷也不產生張力。把再次按鍵放進裝填進度之中，等於在等待裡插入一個小目標，讓中斷時間仍然需要專注。它適合彈藥有限、交戰節奏緊湊、換彈頻繁的射擊情境，因為玩家本來就必須反覆面對這段空檔。

反之，若遊戲主打慢速戰術、換彈本來就稀少，或裝填已被設計成明確的懲罰節奏，硬加一層按鍵只會稀釋原本的重量。單場換彈次數太少時，玩家也難以建立手感，獎勵就變成運氣。

## 核心循環（本地分析）

- 玩家行動：玩家在彈藥見底或攻勢空檔時主動按下裝填，接著把一部分視線分給進度條，等指標掃進可見的成功區時再按一次。
- 系統回饋：進度條上標出成功區；達標時裝填可提前完成，或讓下一彈匣以強化狀態開始，失手則回到一般裝填或承受較長的裝填時間，兩種結果都立刻反映在彈藥狀態與後續射速上。
- 下一個決策：拿到強化彈匣或提前完成裝填後，玩家更願意立刻投入下一次交戰；若失手或判斷失誤，下一個決策就偏向先退開、等安全再換彈，形成風險承擔與否的分歧。

## 解法與取捨（本地分析）

- 成功區越窄，獎勵越像技術證明，但也越容易在遭到追趕時被放棄；獎勵價值必須大到值得冒險，又不能大到讓沒按到的玩家覺得吃虧。
- 失敗後果若只是少一點獎勵，玩家會無腦每次都按；若直接卡住整把槍，失手一次就可能讓整場交戰崩掉，需要在兩者之間找到可承受的懲罰。
- 成功後的效益若延續太久，會壓縮後續換彈決策的空間；若只影響一兩發或只是略早完成裝填，玩家又懶得為它分神。

## 可調參數（本地分析）

- 「成功區寬度」：往窄調，按鍵時機變成硬技術門檻，玩家在安全時才敢嘗試，獎勵的使用頻率下降；往寬調，多數人都能輕鬆命中，按鍵變成反射動作，判斷成分被稀釋。
- 「失敗後果」：往輕調（僅損失獎勵），玩家幾乎每次都按，因為沒有下行風險；往重調（延長裝填、卡彈或中斷換彈），玩家會更嚴格挑安全時機，失手一次的代價也放大到影響整場交戰。

## 失敗模式（本地分析）

- 成功區若固定在進度條同一位置，玩家只要背下節奏就能閉眼按，判斷變成肌肉記憶，走位壓力也不再影響表現。
- 換彈動畫太短或太快，玩家根本看不清指標位置，按鍵就成了碰運氣；反之動畫過長，每次換彈都被迫中斷戰鬥，累積起來很煩躁。
- 在需要高度走位的追逐戰中，若成功區獎勵差距過大，玩家會為了按鍵而忽略閃避，反而讓機制與戰鬥核心互相拉扯。

## 最小原型與驗收（本地提案）

此原型尚未實玩驗證；範圍與數字都是本地測試設定，不是來源遊戲參數。

- 最小範圍：單一武器、單一換彈動畫：一條 1.2 秒的進度條，成功區設在 0.7～0.9 秒之間，以第二次按鍵判定；用寬區與窄區兩組設定各跑幾次，記錄按鍵時機與結果。
- 驗收：Given 給定一把彈匣容量 8 發、目前 0 發的武器，裝填動畫 1.2 秒，成功區位於裝填開始後 0.70～0.90 秒，命中則彈匣轉為強化狀態（傷害 +20%），失手則裝填延長至 1.8 秒。 When 玩家在 0 秒按下裝填開始裝填，並在裝填開始後 0.80 秒再次按鍵，此時第二次按鍵落在 0.70～0.90 秒的成功區內。 Then 系統判定命中成功區，裝填於 1.2 秒後完成，彈匣由 0 發補滿為 8 發並標記為強化，HUD 顯示強化圖示，下一發傷害提高 20%。
- 邊界驗收：Given 同一把武器，成功區收窄為 0.75～0.82 秒，失敗後果改為裝填時間不變但失去強化。 When 玩家在裝填開始後 0.90 秒才按下第二次按鍵，已超出成功區，且此時正被兩名敵人追趕。 Then 系統判定失手，裝填仍於 1.2 秒完成，彈匣由 0 發補滿為 8 發但無強化標記；預期記錄會顯示窄區設定下命中次數變少，且玩家在被追趕時更常直接放棄按鍵。

## 相關模式

- [蓄力後釋放](projectiles-charged-release.md)：兩者都把按鍵時機往後推遲以換取更大回報，但蓄力是在出手前決定力道，主動裝填則是在中斷期間插入判斷，風險來源是被追打而非錯過出手窗口。
- [擦彈獎勵](projectiles-graze-reward.md)：兩者都在安全之外的收益上加碼，差別在擦彈要求玩家靠近危險，主動裝填則要求在換彈空檔中分神盯住進度條。
- [熱度節奏](projectiles-heat-pacing.md)：兩者都在管理開火節奏，但熱度節奏是提前停火以避免懲罰，主動裝填則是把那段不能射擊的時間變成可以爭取的獎勵。
- [停火以收回彈道散布](projectiles-spread-recovery.md)：兩者都要求玩家暫停輸出，不過散布恢復是被動等待準度回來，主動裝填得在等待中再按一次才有額外收益。
