Motion Prompt #066 · ui/breadcrumbs

Meaning: A trail of links showing where the page sits in the site
Example request (adapt to your project): Add breadcrumbs above the article: "Home › Courses › Web design", with the current page in bold and not linked.
What this demo shows: Clicking "Courses" in the breadcrumbs goes up to the list page; clicking a card there returns to the detail page.
Demo specification (independent of the example request):
- 4.5 s cycle on a 542×191 card. At the top "Home › Courses › Web design" (in the selected language, 17 px): links blue, current page black and bold; a divider at y 46.
- The cursor hovers "Courses" (underline 0.9–1.2 s) and clicks at 1.0 s.
- Up amount: 0→1 over 1.0–1.25 s with easeInOutCubic. "› Web design" fades out and "Courses" becomes the current page (black, bold).
- Content cross-fades from a detail page (title and text) to a list of three cards (158×118, with a landscape picture).
- Back: the cursor moves onto the first card (blue outline 2.45–2.8 s) and clicks at 2.7 s; the detail page returns over 2.7–2.95 s.
When to use it: Use it on sites with deep hierarchies to show where the page is and give a way back up.
