Motion Prompt #083 · lp/cursor-follower

Meaning: A shape trails the mouse pointer with a delay
Example request (adapt to your project): Add a cursor follower across the site: a 30 px orange circle that trails the pointer slightly.
What this demo shows: As the cursor moves around the page, an orange circle follows it a little behind.
Demo specification (independent of the example request):
- Cursor path: x = 255 + 175·sin(2πt/4.8), y = 86 + 46·sin(4πt/4.8) (a figure eight lying on its side, one lap per 4.8 s).
- Circle: radius 17, orange, opacity 0.88, drawn under the cursor.
- Follow rule: every frame (60 fps) it covers 12% of the remaining distance (x += (cursor x − x) × 0.12).
- The arrow cursor stays visible.
When to use it: Use it on brand sites and portfolios to add a playful, hands-on feel.
