Motion Prompt #094 · lp/marquee

Meaning: Text or logos scroll across in an endless band
Example request (adapt to your project): Run the service names in a marquee from right to left, looping without a gap, at about 80 px per second.
What this demo shows: Inside a navy band, large service names separated by orange dots keep moving to the left without a gap.
Demo specification (independent of the example request):
- Band: 58 tall, navy, full viewport width. Text: 30 px, heavy weight, 1 px letter spacing, white.
- One set is four words (WEB DESIGN / BRANDING / MOTION / UI/UX), 64 px apart, with an orange dot (radius 6) in each gap.
- Each cycle (4.8 s) moves left by the width of one set (about 881 px here) at constant speed. The set is measured and the offset wraps by that width, so there is no visible seam.
- The set is repeated until the viewport width is filled.
When to use it: Use it to show service names, client logos or a tagline with energy.
