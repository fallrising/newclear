//   - 白天→夜晚→白天，各段 2.35 s；每半段的 0.45–1.6 s 進行轉換（1.15 s），採三次方 ease-in-out。
//   - 下一幕疊在目前場景上，並裁切於形狀內；形狀擴大直到覆蓋整個畫面。
//   - 白天→夜晚：以太陽中心（112, 104）為圓心，半徑 0→470。
//   - 夜晚→白天：以月亮中心（427, 104）展開五角星，外半徑 0→1150，擴大時同時旋轉 1.2 rad（約 69°）。
//   - 擴大過程中，形狀邊緣有白色外框（寬 7）。
// 使用情境: 適合從畫面中的太陽、標誌或按鈕等物體開始切換場景。
// 關鍵字: mask, transition, iris, wipe, shape-wipe, reveal, scene-change

// 需要: kit motion -> ./api/v1/kit/zh-Hant/motion.js
// 本地示範: ./?lang=zh-Hant#017

// cells[i](k, w, h, u)：k = CanvasRenderingContext2D，呼叫端先清除畫布並以 save/restore 包覆；w、h 為尺寸，u 為 [0, cycle) 內的秒數。畫面只取決於 u。
// 下方是元素程式碼；CELLS、常數與輔助函式位於 kit。

// @element 17

CELLS[16] = abCell((k, w, h, u, a, b) => {
  const p = eIO(P(u, TA - 0.05, TB + 0.1));
  SCR[a](k, w, h);
  if (p > 0) {
    const c = a === 0 ? SUN : MOON, shape = () => { if (a === 0) { k.beginPath(); k.arc(c[0], c[1], lerp(0, 470, p), 0, 7); } else star(k, c[0], c[1], lerp(0, 1150, p), p * 1.2, 0.5); };
    k.save(); shape(); k.clip(); SCR[b](k, w, h); k.restore();
    if (p < 1) { k.strokeStyle = '#fff'; k.lineWidth = 7; k.lineJoin = 'round'; shape(); k.stroke(); }
  }
});
