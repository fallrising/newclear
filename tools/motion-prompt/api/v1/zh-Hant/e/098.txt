// 輪廓光（Rim light）
// 分類組: photo (攝影效果、打光與風格) · element 02 · 分類: 打光與時段
// 示範內容: 周圍變暗，人物左右後方的兩盞燈只在頭部與肩膀兩側畫出細亮邊；右下方俯視圖顯示兩盞燈的位置。
// 動作／視覺規格:
//   - 場景 1：地平線位於 y 150，前方為頭肩人物，頭部中心 x 270、y 78、半徑 29 px，沒有臉部或頭髮。
//   - 背景從明亮場景變為暗色場景：天空 #2B2D33、地面 #24252A；人物 #4D5A75 → #1F2128。
//   - 亮邊：兩份琥珀色 #FFC75A 人物輪廓，各向左右偏移 3.5 px、向上偏移 2.5 px，置於深色人物後方，形成 3.5 px 寬的邊緣。
//   - 右下方俯視圖為 66×66 px，燈光位於 ±135°，也就是左右後方；右上讀值為「±135°」。
//   - 時間：0.4 s 到 1.4 s 漸入，維持至 4.0 s，於 4.8 s 前退去；每輪 = 5 s，採 cubic ease-in-out，約為 cubic-bezier(0.65,0,0.35,1)。
// 使用情境: 適合將人物或產品從暗背景中分離，突出形狀。
// 關鍵字: rim light, rim lighting, edge light, backlight, kicker, outline, studio
// 尺寸: 539x208 px · 週期: 5 s
// 需要: kit photo -> ./api/v1/kit/zh-Hant/photo.js
// 本地示範: ./?lang=zh-Hant#098
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D，呼叫端先清除畫布並以 save/restore 包覆；w、h 為尺寸，u 為 [0, cycle) 內的秒數。畫面只取決於 u。
// 下方是元素程式碼；CELLS、常數與輔助函式位於 kit。

// @element 02

CELLS[1] = cell((k, u) => {
  const a = env(u);
  stagePortrait(k, pal(BASE, DARK, a));
  k.save(); k.globalAlpha = a; k.fillStyle = BASE.lit;
  for (const dx of [-3.5, 3.5]) { k.save(); k.translate(dx, -2.5); bustPath(k, PX, PY, PR); k.fill(); k.restore(); }
  k.restore();
  bust(k, PX, PY, PR, mixc(BASE.person, DARK.person, a));
  plan(k, [[Math.PI * 0.75, a], [-Math.PI * 0.75, a]]);
  hud(k, '±135°');
});
