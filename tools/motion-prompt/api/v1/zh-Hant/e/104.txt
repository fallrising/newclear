// 藍調時刻（Blue hour）
// 分類組: photo (攝影效果、打光與風格) · element 08 · 分類: 打光與時段
// 示範內容: 太陽落下後，天空變成兩段深藍色，窗戶與路燈亮起琥珀光，人物變為深藍色輪廓。
// 動作／視覺規格:
//   - 場景 1：地平線位於 y 150，前方為頭肩人物，頭部中心 x 270、y 78、半徑 29 px，沒有臉部或頭髮。
//   - 太陽半徑 18 px，位於 x 120；效果進度達 70% 前，從 y 40 降至 y 190，在 40% 到 80% 之間淡出。
//   - 色彩：天空頂部 #2C3B5E、地平線附近 #4A6191，地面 #283452、建築 #34446B、人物 #1C2439。
//   - 燈光：每三扇窗有一扇與路燈燈泡變為 #FFC75A；燈泡外有 13 px 與 8 px 的平面光圈，#FFE3A3、不透明度 35% 與 60%。
//   - 右上時間 12:00 → 18:35。
//   - 時間：0.4 s 到 1.4 s 漸入，維持至 4.0 s，於 4.8 s 前退去；每輪 = 5 s，採 cubic ease-in-out，約為 cubic-bezier(0.65,0,0.35,1)。
// 使用情境: 適合同時需要藍色天空與發光燈火的城市夜景。
// 關鍵字: blue hour, twilight, dusk, night city, cityscape, deep blue sky
// 尺寸: 539x208 px · 週期: 5 s
// 需要: kit photo -> ./api/v1/kit/zh-Hant/photo.js
// 本地示範: ./?lang=zh-Hant#104
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D，呼叫端先清除畫布並以 save/restore 包覆；w、h 為尺寸，u 為 [0, cycle) 內的秒數。畫面只取決於 u。
// 下方是元素程式碼；CELLS、常數與輔助函式位於 kit。

// @element 08

CELLS[7] = cell((k, u) => {
  const a = env(u);
  const p = pal(BASE, NIGHT, a);
  stagePortrait(k, p, {
    sun: [120, lerp(40, 190, P(a, 0, 0.7)), 18, 1 - P(a, 0.4, 0.8)],
    after: D => { const k2 = D.k; k2.save(); k2.globalAlpha = 0.35 * a; D.circ(413, HZ - 53, 13, BASE.glow); k2.globalAlpha = 0.6 * a; D.circ(413, HZ - 53, 8, BASE.glow); k2.restore(); D.circ(413, HZ - 53, 4, p.bulb); }
  });
  bust(k, PX, PY, PR, p.person);
  hud(k, clock(lerp(720, 1115, a)));
});
