// 魚眼鏡頭（Fisheye lens）
// 分類組: photo (攝影效果、打光與風格) · element 14 · 分類: 鏡頭與相機效果
// 示範內容: 街景中央向外膨脹，建築的垂直線與道路線條向外彎曲，四個角落保持原位。
// 動作／視覺規格:
//   - 場景 2：街角的建築、樹木與路燈（x 114、292、494）位於 y 132–162 的道路後方；人物站在左前方，腳位於 x 176、y 200，身高 124 px。
//   - 變形：距中心 d 的點移到原距離的 g = (1 + k) / (1 + k·d²/R²) 倍；R 是中心至角落的距離（289 px）。
//   - k 從 0 → 1.25；中心放大 2.25×，角落不移動。
//   - 每條輪廓在變形前每隔 6 px 分段，讓直線變成曲線。
//   - 右上焦距：24mm → 8mm。
//   - 時間：0.4 s 到 1.4 s 漸入，維持至 4.0 s，於 4.8 s 前退去；每輪 = 5 s，採 cubic ease-in-out，約為 cubic-bezier(0.65,0,0.35,1)。
// 使用情境: 適合大膽、趣味或窺視孔般的視角，如滑板或音樂影片。
// 關鍵字: fisheye, fisheye lens, barrel distortion, ultra wide, 8mm, distortion
// 尺寸: 539x208 px · 週期: 5 s
// 需要: kit photo -> ./api/v1/kit/zh-Hant/photo.js
// 本地示範: ./?lang=zh-Hant#110
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D，呼叫端先清除畫布並以 save/restore 包覆；w、h 為尺寸，u 為 [0, cycle) 內的秒數。畫面只取決於 u。
// 下方是元素程式碼；CELLS、常數與輔助函式位於 kit。

// @element 14

CELLS[13] = cell((k, u) => {
  const a = env(u), kk = 1.25 * a, cx = CW / 2, cy = CH / 2, R2 = cx * cx + cy * cy;
  const M = kk < 0.002 ? null : (x, y) => { const dx = x - cx, dy = y - cy, g = (1 + kk) / (1 + kk * (dx * dx + dy * dy) / R2); return [cx + dx * g, cy + dy * g]; };
  stageStreet(k, BASE, { M });
  hud(k, `${Math.round(lerp(24, 8, a))}mm`);
});
