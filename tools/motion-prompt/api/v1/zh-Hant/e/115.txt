// 分類組: photo (攝影效果、打光與風格) · element 19 · 分類: 色調與後製風格
// 示範內容: 同一片景色的色彩逐漸退去，太陽與人物受光處變成灰色，只靠亮度區分形狀。
// 動作／視覺規格:
//   - 場景 3：左側為胸像，頭部中心 x 140、y 82、半徑 28 px；右側有山丘、房屋、樹木與太陽，太陽位於 x 432、y 54、半徑 15 px。
//   - 轉換：每個色彩依亮度變為灰階（0.2126R + 0.7152G + 0.0722B），以 140 為中心將對比乘以 1.25。
//   - 例如人物 #4D5A75 → 約 #4D4D4D，太陽 #F5A524 → 約 #B5B5B5。
//   - 時間：0.4 s 到 1.4 s 漸入，維持至 4.0 s，於 4.8 s 前退去；每輪 = 5 s，採 cubic ease-in-out，約為 cubic-bezier(0.65,0,0.35,1)。
// 使用情境: 適合雋永的感覺，或比起色彩更重視形狀、光線與表情的畫面。
// 關鍵字: black and white, monochrome, b&w, grayscale, desaturated, classic
// 尺寸: 539x208 px · 週期: 5 s
// 需要: kit photo -> ./api/v1/kit/zh-Hant/photo.js
// 本地示範: ./?lang=zh-Hant#115
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D，呼叫端先清除畫布並以 save/restore 包覆；w、h 為尺寸，u 為 [0, cycle) 內的秒數。畫面只取決於 u。
// 下方是元素程式碼；CELLS、常數與輔助函式位於 kit。

// @element 19

CELLS[18] = cell((k, u) => {
  const a = env(u);
  const GRAY = mapPal(BASE, c => { const g = clamp((lum(c) - 140) * 1.25 + 140, 0, 255); return toHex([g, g, g]); });
  stageLand(k, pal(BASE, GRAY, a));
});
