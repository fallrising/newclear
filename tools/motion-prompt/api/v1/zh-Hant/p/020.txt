Motion Prompt #020 · motion/zoom-through

意思：放大進入物體內部，穿越到下一幕
向 AI 描述的例句（可依專案調整）：以穿越式放大進入標誌中字母 O 的孔洞，通往下一幕，0.6 s，逐漸加速。
此示範的內容：視角衝進字母 O 的孔洞，穿出後進入下一幕。
示範規格（與提問例句分開）：
- 場景 X（黃底 ZOOM）→場景 Y（藍底 GO!）→場景 X，各段 2.35 s。
- 目前場景以 O 的孔洞中心（半徑 24.5）為基準放大；最大倍率為孔洞覆蓋整個畫面所需值的 1.08×（約 14×）。
- 縮放 = maxScale^p（指數放大，視覺上近似等速）。
- p = 0.8 × 三次方 ease-in（0.25–1.2 s）+ 0.2 × 三次方 ease-out（1.2–1.65 s）：先加速衝入，最後減速。
- 孔洞內的下一幕先縮至 1/maxScale；放大結束時正好恢復原尺寸，再切換到下一幕。
使用情境：適合深入標誌或字母內部，帶著動勢銜接下一幕。
