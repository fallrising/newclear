Motion Prompt #034 · camera/handheld

意思：像手握攝影機般輕微晃動
向 AI 描述的例句（可依專案調整）：從後方手持跟拍步行人物，只保留輕微晃動。
此示範的內容：整個畫面有細微、不規則的晃動，像用手握住攝影機而非架在腳架上。
示範規格（與提問例句分開）：
- 攝影機：位置近乎固定；水平偏角、俯仰、翻滾與高度各疊加不同週期的正弦波（T = 2π×u/4.7）。
- 水平偏角（rad）= 0.016·sin(3T) + 0.008·sin(7T+1) + 0.004·sin(13T+2)，最多約 ±1.6°。
- 俯仰角（rad）= 0.012·sin(4T+2) + 0.006·sin(9T+0.5) + 0.003·sin(17T+1.2)，最多約 ±1.2°。
- 翻滾角（rad）= 0.02·sin(5T+1) + 0.008·sin(11T+3)，最多約 ±1.6°；高度 = 1.5 + 0.03·sin(6T) m。
- 主體：人物靜止站在前方 6.5 m；晃動持續進行，無緩動或停留。
- 各頻率倍數皆為整數，因此每 4.7 s 無縫循環；右上角顯示手持狀態。
使用情境：適合營造紀錄片質感或身在現場的感覺。
