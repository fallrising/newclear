Motion Prompt #047 · camera/j-cut

意思：下一幕的聲音先於畫面出現
向 AI 描述的例句（可依專案調整）：使用 J-cut：下一幕的海浪聲先響起，再切到海景。
此示範的內容：下一幕聲音先開始，畫面稍後切換；上方展示畫面，下方是影像與音訊時間軸。
示範規格（與提問例句分開）：
- 接點：畫面直接硬切，音訊提前換成下一幕 B；偏移為時間軸的 20%（0.72 s）。
- 播放頭：在 3.6 s 內（0.4 s 至 4.0 s）由左至右等速移動；音訊在 35%（約 1.66 s）切換，影像在 55%（約 2.38 s）切換。
- 錯開區間（35–55%）中，影像仍是 A，音訊已是 B；以淡藍色帶與兩條藍色虛線標示。
- 版面：上方 134 px 是畫面（固定攝影機、主體不動）；下方 74 px 放影像與音訊兩列時間軸（A 灰色、B 淡藍色，音訊列有波形）。
- 標籤：畫面左下為「影像 A／影像 B」；右下顯示目前音訊，由灰色「♪ A 音訊」變為藍色「♪ B 音訊」。
- 回到起點：最後 0.5 s 交叉淡化回起始畫面（一輪 = 4.7 s）。
使用情境：適合預告下一幕，或讓換場與換說話者更自然。
