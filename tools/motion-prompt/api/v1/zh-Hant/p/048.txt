Motion Prompt #048 · camera/l-cut

意思：前一幕的聲音延續到下一幕
向 AI 描述的例句（可依專案調整）：使用 L-cut：保留她的聲音，同時切到聆聽者的臉。
此示範的內容：畫面切換後，前一幕聲音仍延續片刻；上方展示畫面，下方是影像與音訊時間軸。
示範規格（與提問例句分開）：
- 接點：畫面直接硬切，音訊延後才換成下一幕 B；偏移為時間軸的 20%（0.72 s）。
- 播放頭：在 3.6 s 內（0.4 s 至 4.0 s）由左至右等速移動；影像在 55%（約 2.38 s）切換，音訊在 75%（約 3.10 s）切換。
- 錯開區間（55–75%）中，影像已是 B，音訊仍是 A；以淡藍色帶與兩條藍色虛線標示。
- 版面：上方 134 px 是畫面（固定攝影機、主體不動）；下方 74 px 放影像與音訊兩列時間軸（A 灰色、B 淡藍色，音訊列有波形）。
- 標籤：畫面左下為「影像 A／影像 B」；右下顯示目前音訊，由灰色「♪ A 音訊」變為藍色「♪ B 音訊」。
- 回到起點：最後 0.5 s 交叉淡化回起始畫面（一輪 = 4.7 s）。
使用情境：適合保留說話者聲音，同時展示聆聽反應或相關畫面。
