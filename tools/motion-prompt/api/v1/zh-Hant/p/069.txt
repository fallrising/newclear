Motion Prompt #069 · ui/skeleton-screen

意思：載入時用灰色形狀預示內容位置
向 AI 描述的例句（可依專案調整）：清單載入時顯示骨架畫面：灰色區塊對應內容形狀，每 0.9 s 有一道亮光由左至右掃過。
此示範的內容：點重新整理後，清單變成相同形狀的灰色區塊並出現掃光；載入結束後恢復內容。
示範規格（與提問例句分開）：
- 542×191 卡片上每 4.5 s 循環。兩列清單，每列含 96×56 圖片與三行文字；游標於 1.0 s 點擊右上重新整理圖示。
- 於 1.05–1.2 s 線性切換成灰色 #e9e7e5 圓角區塊，尺寸與位置不變。
- 掃光：寬 160 的白色光帶，兩側透明、中央不透明度 0.75；每 0.9 s 從 x −200 掃至 x 742，只畫在區塊上。
- 內容於 3.0–3.3 s 線性恢復。
使用情境：適合需要短暫載入的清單或卡片，等待時仍能看到版面結構。
