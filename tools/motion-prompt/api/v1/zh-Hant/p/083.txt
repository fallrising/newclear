Motion Prompt #083 · lp/cursor-follower

意思：圖形稍有延遲地跟隨滑鼠游標
向 AI 描述的例句（可依專案調整）：整個網站加入游標跟隨：一個 30 px 橘色圓形稍微落後游標移動。
此示範的內容：游標在頁面上移動時，橘色圓形落後一小段距離跟隨。
示範規格（與提問例句分開）：
- 游標路徑：x = 255 + 175·sin(2πt/4.8)，y = 86 + 46·sin(4πt/4.8)，形成橫躺的八字形，每 4.8 s 一圈。
- 圓形半徑 17，橘色，不透明度 0.88，畫在游標下方。
- 跟隨規則：每一影格（60 fps）移動剩餘距離的 12%，即 x += (cursor x − x) × 0.12。
- 箭頭游標保持可見。
使用情境：適合品牌網站與作品集，增加遊戲感與操作回饋。
