Motion Prompt #085 · lp/ripple-effect

意思：從按下的位置向外擴散漣漪
向 AI 描述的例句（可依專案調整）：送出按鈕加入漣漪效果：白色圓形從點擊位置擴散，在 0.6 s 內淡出。
此示範的內容：每次點擊都會從點擊位置擴散白色圓形，填滿按鈕後消失。
示範規格（與提問例句分開）：
- 橘色按鈕為 280 × 56，圓角半徑 10；0.7 s 點擊中央偏左，2.9 s 點擊中央偏右。
- 圓形以點擊位置為中心，半徑在 0.6 s 內從 0 增至按鈕最遠角落的距離（cubic ease-out）。
- 白色不透明度為 0.4，在點擊後 0.3 到 0.8 s 之間淡至 0。
- 圓形裁切在按鈕內（overflow: hidden），文字位於圓形上方。
使用情境：適合在按鈕或清單項目上，於實際點擊位置提供確認回饋。
