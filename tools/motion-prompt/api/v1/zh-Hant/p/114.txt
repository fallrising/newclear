Motion Prompt #114 · photo/low-key

意思：暗色畫面中，只讓受光部分突出
向 AI 描述的例句（可依專案調整）：黑底上的威士忌瓶低調攝影，只用單一側光，僅受光邊緣顯現，大部分畫面為深黑色。
此示範的內容：大部分畫面沉入黑暗，太陽消失；只有胸像受側光照亮的右側邊緣保持明亮，直方圖峰值移向左端。
示範規格（與提問例句分開）：
- 場景 3：左側為胸像，頭部中心 x 140、y 82、半徑 28 px；右側有山丘、房屋、樹木與太陽，太陽位於 x 432、y 54、半徑 15 px。
- 色彩：天空 #FAF9F7 → #2B2D33，山丘 → #313339 與 #36383E，地面 → #24252A，人物 → #25272E；太陽與光圈變成天空色而消失。
- 胸像受光的右側邊緣保留，#FFC75A → #FFB547。
- 直方圖峰值中心 0.56 → 0.14，寬度 0.2 → 0.08。
- 時間：0.4 s 到 1.4 s 漸入，維持至 4.0 s，於 4.8 s 前退去；每輪 = 5 s，採 cubic ease-in-out，約為 cubic-bezier(0.65,0,0.35,1)。
使用情境：適合奢華、緊張或神祕的影像。
