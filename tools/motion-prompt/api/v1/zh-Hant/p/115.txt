Motion Prompt #115 · photo/black-and-white

意思：移除色彩，只呈現明暗
向 AI 描述的例句（可依專案調整）：海灘隨拍轉為黑白，稍微提高對比，保留天空與沙地的明暗差異。
此示範的內容：同一片景色的色彩逐漸退去，太陽與人物受光處變成灰色，只靠亮度區分形狀。
示範規格（與提問例句分開）：
- 場景 3：左側為胸像，頭部中心 x 140、y 82、半徑 28 px；右側有山丘、房屋、樹木與太陽，太陽位於 x 432、y 54、半徑 15 px。
- 轉換：每個色彩依亮度變為灰階（0.2126R + 0.7152G + 0.0722B），以 140 為中心將對比乘以 1.25。
- 例如人物 #4D5A75 → 約 #4D4D4D，太陽 #F5A524 → 約 #B5B5B5。
- 時間：0.4 s 到 1.4 s 漸入，維持至 4.0 s，於 4.8 s 前退去；每輪 = 5 s，採 cubic ease-in-out，約為 cubic-bezier(0.65,0,0.35,1)。
使用情境：適合雋永的感覺，或比起色彩更重視形狀、光線與表情的畫面。
