Motion Prompt #116 · photo/duotone

意思：以兩種顏色分別表現暗部與亮部
向 AI 描述的例句（可依專案調整）：人像照片改為深藍與粉紅雙色調：暗部深藍、亮部粉紅，不加入其他顏色。
此示範的內容：同一片景色的色彩被替換為兩色之間的範圍：暗部靛藍、亮部粉紅。
示範規格（與提問例句分開）：
- 場景 3：左側為胸像，頭部中心 x 140、y 82、半徑 28 px；右側有山丘、房屋、樹木與太陽，太陽位於 x 432、y 54、半徑 15 px。
- 兩個端點色：暗部 #1F2A5C、亮部 #FF9FB2。
- 轉換：由各色彩亮度 L 計算 t = ((L − 70) / 180)^2.4，再以 t 混合兩色，拉開亮部色調的差異。
- 時間：0.4 s 到 1.4 s 漸入，維持至 4.0 s，於 4.8 s 前退去；每輪 = 5 s，採 cubic ease-in-out，約為 cubic-bezier(0.65,0,0.35,1)。
使用情境：適合用品牌色統一海報、音樂封面或社群圖片。
