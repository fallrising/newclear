Motion Prompt #119 · photo/light-leak

意思：像光線漏進底片般的紅橘光暈
向 AI 描述的例句（可依專案調整）：夏日回憶照片，右側邊緣滲入紅色與橘色漏光。
此示範的內容：同一片景色的右側邊緣滲入一道漏光，內側淡黃、邊緣紅色，緩慢擺動。
示範規格（與提問例句分開）：
- 場景 3：左側為胸像，頭部中心 x 140、y 82、半徑 28 px；右側有山丘、房屋、樹木與太陽，太陽位於 x 432、y 54、半徑 15 px。
- 形狀為四個高橢圓，中心在右緣外 30 px，循環中擺動 ±6 px；垂直半徑為畫面高度的 1.1×。
- 水平半徑與色彩：250 px #FFD089、不透明度 35%；170 px #FF9A3D、40%；95 px #FF5A3A、45%；45 px #FF3B30、50%；各自從 0 長到指定半徑。
- 時間：0.4 s 到 1.4 s 漸入，維持至 4.0 s，於 4.8 s 前退去；每輪 = 5 s，採 cubic ease-in-out，約為 cubic-bezier(0.65,0,0.35,1)。
使用情境：適合懷舊、夏日、像偶然拍下的回憶。
