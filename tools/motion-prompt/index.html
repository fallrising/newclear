從畫面到提示詞

  1. 1

    觀看與搜尋

    以繁中、英文或編號搜尋，也可以按分類瀏覽。點擊示範，查看意思、用途與實際規格。

  2. 2

    選取與組合

    按「選取」加入清單，可加入多項並填寫用途備註。切換介面語言仍會保留搜尋、選取與備註。

  3. 3

    選擇語言並複製

    提示詞可獨立選擇繁中或英文。複製單項或整份選取清單，再貼到你使用的 AI 工具。

關於示範

示範以 Canvas 2D 在本機繪製，不需要帳號或外部服務。尊重系統的減少動態設定，也可隨時暫停。
